## 1. 产品概述

### 1.1 背景与问题

海豚银行是明德学校面向学生的校园银行，学生以海豚币办理存取、兑换文创和贷款，由学生社员担任柜员、财务、库管、行长，银行管理员负责管理。目前账本是一张 Excel 表，靠公式计算存入、取出和利息，带来以下问题：

- **容易出错**：柜员手工录入、手工算钱，四年级学生输错学号、算错找零的情况难以避免。
- **难以对账**：每班次结束时无法快速核对储蓄盒现金与账面是否一致，差错难以追溯到人和时间。
- **缺少约束**：表格里余额可以直接改、记录可以直接删，透支、超卖、重复记账没有硬性拦截。
- **信息不透明**：学生、老师、家长无法随时查看账户情况，库存、发行量、贷款等经营数据要靠人工统计。

### 1.2 产品定位

一个让小学生也能准确、轻松办理业务的**校园银行业务平台**：柜台办业务、后台管经营、银行管理员管货币与审批，并逐步延伸到智慧校园的家长端和教师端。

### 1.3 产品原则

1. **账永远对得上**：余额只能由业务流水推出，错账用冲正更正，记录不删除。
2. **办理与审批分离**：柜员能发起，不能批准；每个角色只做自己权限内的事。
3. **孩子用得会**：大按钮、少层级、说孩子听得懂的话，界面文字与《柜台业务 SOP 卡片》一致。
4. **纸质兜底**：凭条留存、离线可登记，系统故障时业务不中断、记录不丢失。

## 2. 用户与角色

| 角色 | 由谁担任 | 在平台上做什么 | 首次可用阶段 |
| --- | --- | --- | --- |
| 学生 | 全体社员及开户学生 | 查询本人余额、明细、贷款 | 阶段一 |
| 柜员 | 出纳、支行负责人（当班） | 办理存款、取款、兑换/购买，录入贷款申请，发起冲正 | 阶段一 |
| 财务 | 老成员（复核岗） | 查看全部流水、核对柜台业务、导出报表 | 阶段一 |
| 库管 | 老成员 | 文创商品上架/下架、入库、盘点 | 阶段一 |
| 银行管理员 | 管理员 | 后台的全部操作：货币发行、用户与权限、参数设置、复核轧账、工资发放、查看全部报表等；柜台业务由当班柜员办理，系统故障时用手动补录 | 阶段一 |
| 运维员 | 信息技术老师 | 账号维护、数据备份与恢复、日志审计（不改业务数据） | 阶段一 |
| 行长 | 学生负责人 | 查看经营全貌与各项业务、轧账、考勤签到与作废；查看风险提醒；学生、人员、参数和日志由银行管理员管理 | 阶段二 |
| 班主任 / 科任老师 / 社团老师 | 教师端用户 | 发放、奖励、扣除本班或社团学生的海豚币，发工资，查看报表 | 阶段三 |

每个账号只有一种身份：学生账号只用来查看自己的账户；柜员、财务、库管、银行管理员、运维员各用一个独立的工作账号，与担任者是学生还是老师无关。同一个人担任两种身份时持有两个账号，在同一台设备上登录后可以一键切换，不必反复输入密码。

## 3. 分阶段总览

| 阶段 | 主题 | 一句话目标 | 主要使用者 |
| --- | --- | --- | --- |
| **阶段一** | 柜台上线，替代 Excel 账本 | 日常存、取、兑换全部在系统中完成，办错的业务能当场冲正 | 柜员、财务、库管、银行管理员、学生 |
| **阶段二** | 完善运营与管理 | 胸卡扫码、贷款、盘点、发行监控、报表都有完整流程，银行管理员随时看得到经营全貌 | 新增行长；财务与老师用得更深 |

## 4. 阶段一：柜台上线，替代 Excel 账本

### 4.1 阶段目标

- 柜台日常业务（存款、取款、兑换文创）全部在系统中办理，停用 Excel 账本。
- 办错的业务由柜员当场冲正，每一笔流水都能查到经办人和时间。
- 学生能自助查到自己的余额和最近交易。

### 4.2 功能范围

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 账户 | 批量开户 / 导入名册 | 银行管理员导入学生名册后自动为每位学生开户，初始余额为 0；支持把现有 Excel 账本的余额迁入 |
| 账户 | 身份识别 | 学生用学号 + 密码登录；柜台按姓名、拼音、班级或学号找到学生，确认是本人后，一次办完这位学生的多项业务 |
| 账户 | 学生查询 | 余额、交易明细、存款排名（小学部、初中部分开排，可匿名） |
| 柜台 | 存款 | 按面额（1/2/5/10 元）录入张数，自动算总额 |
| 柜台 | 取款 | 余额不足禁止提交；自动给出配钞方案 |
| 柜台 | 兑换 / 购买文创 | 显示商品与实时库存；可从账户扣款，也可现金支付并显示找零；扣款、扣库存、记账同时完成 |
| 柜台 | 冲正 | 柜员冲正本人当天办错的业务，生成反向流水，原记录保留并标记「已冲正」；银行管理员可冲正任意业务 |
| 文创商城 | 商品管理 | 商品名称、图片、价格、上架状态 |
| 对账 | 流水查询 | 财务与银行管理员按学生、日期、类型、柜员查询全部流水 |
| 对账 | 上班与下班 | 柜员上班后才能办理业务；下班时打印本次上班的全部业务，签字留存 |
| 系统 | 用户、角色、权限 | 按角色授权，所有操作留痕 |
| 系统 | 数据备份与恢复 | 每日自动备份，运维员一条命令即可恢复 |
| 系统 | 离线登记 | 断网时柜台可登记存款并暂存本机，恢复后补传；配合纸质单据兜底 |

### 4.3 关键用户故事

**柜员**
- 作为当班柜员，我想输入同学的名字、拼音首字母、班级或学号就能找到这位同学，先确认是本人，再看到余额办理，这样不会办错人。
- 作为当班柜员，我想按面额输入收到的张数，由系统算出总额，这样不用心算，也不会算错。
- 作为当班柜员，我想在取款时看到「10 元 × 2 张、5 元 × 1 张」这样的配钞提示，这样能快速配好钱。
- 作为当班柜员，我想在同学余额不够时被系统直接拦住，这样不会出现透支。
- 作为当班柜员，我想在办错一笔业务后当场冲正，这样不用涂改，记录也清清楚楚。

**财务**
- 作为复核财务，我想按日期、柜员、业务类型查到每一笔流水，这样能逐笔核对柜台业务。

**学生**
- 作为学生，我想登录后就能看到自己有多少海豚币和最近的交易，这样我清楚自己的钱去哪了。

**库管 / 银行管理员**
- 作为库管，我想上架新文创并设置价格和图片，这样柜台马上就能兑换。
- 作为银行管理员，我想一次导入全校名册就完成开户并打印开户通知单，这样不用一个个建账户。
- 作为银行管理员，我想登记每一批发行的海豚币，这样流通的钱都有来历。

### 4.4 业务规则（本阶段生效）

- 余额不能直接修改，只能由业务流水产生变化。
- 禁止透支：取款、消费时余额不足一律拦截。
- 最小金额单位为 1 元，所有金额为整数。
- 单笔、单日取款有限额（建议单笔 ≤ 200、单日累计 ≤ 500），由银行管理员设置。
- 同一笔业务重复提交只记一次账。
- 库存为 0 的商品不可兑换；同时抢购时后到者提示「已售罄」。
- 流水不可删除；办错的业务用冲正更正。柜员只能冲正本人当天办理的业务。

### 4.5 验收标准

- [ ] 柜员在柜台主界面一屏内能看到存款、取款、兑换、查询、冲正入口，任何业务点击不超过 2 层。
- [ ] 余额不足时，取款和兑换无法提交，并提示「余额不足」及可用余额和差额。
- [ ] 兑换成功后，学生余额、商品库存、交易记录三者同时更新；任一项失败则三者都不变。
- [ ] 存款、取款、兑换成功后显示大字结果，如「存款成功，存入 15 HTB，当前余额 43 HTB」。
- [ ] 柜员冲正本人当天的业务后，余额与库存恢复，原记录仍可见并标记「已冲正」。
- [ ] 断网时柜台仍可登记存款，恢复网络后可一键补传，补传后账目与纸质凭条一致。
- [ ] 学生登录后 2 秒内看到余额和最近 10 笔交易。
- [ ] 现有 Excel 账本余额迁入后，与原账本逐人核对一致。

### 4.6 本阶段不包含

- 胸卡扫码、贷款、凭条打印、盘点、报表导出、经营看板 → 阶段二
- 家长端、教师端、存折、利息与定期、积分转海豚币 → 阶段三

## 5. 阶段二：完善运营与管理

> 2026-11-07 与需求方逐项确认后改定，开发细节见 [PHASE-2.md](../development/PHASE-2.md)。阶段一、二合并上线；原阶段三的贷款逾期、利息与定期、旧币回收销毁提前到本阶段。

### 5.1 阶段目标

- 贷款、还款、活期、定期与理财在柜台办理：活期利率就是每周锚点，所有同学相同；贷款利率由每周锚点和海豚信用分决定，与活期同涨同跌，让校园里的海豚币市场保持平稳；定期按银行设定的固定利率；理财随国际市场指数浮动，有赚有亏，让同学体验投资风险。
- 每位柜员每次上班都轧账，现金按面额对得上。
- 银行管理员、行长和财务能随时看到经营全貌和风险提醒，并按学期管理账务。

### 5.2 功能范围

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 账户 | 海豚信用分 | 0～1000 分，初始 600；按还款、存款习惯、账户时长与余额每周加减分（假期照常）；按分数连续计算贷款额度和贷款利率（不分档）；以仪表盘呈现，学生可见；银行管理员可关闭信用分，关闭期间所有学生按 600 分计、分数不变，重新打开后恢复各人原来的分数 |
| 利率 | 每周锚点 | 每周一按存贷比和存款增速用公式算出锚点（初始每周 2%，限 1%～4%），锚点即本周的活期利率，贷款利率也挂在锚点上；利息算作新增发行；学期内和假期一样每周运行 |
| 储蓄 | 活期与定期 | 余额每天计息（假期照常）、每周一结息；柜台可转 2 / 4 / 12 / 24 / 48 周定期，各期限的周利率是银行管理员设定的固定值；可以跨学期，假期照常计息；到期自动转回并付息，可提前支取（按活期计息） |
| 理财 | 浮动收益 | 柜台可买 2 / 4 / 12 / 24 / 48 周的理财，可以跨学期；现值每天更新：当天收益率 = 该期限的基础收益 + 倍率 × 中国股市指数（默认沪深 300）当天的涨跌，A 股休市的日子只有基础收益；基础收益使指数不涨不跌时到期金额比同期限定期略高；倍率由学生买入时在几档里选，最低一档也是指数涨跌的数倍，倍率越高赚得越多、亏得越多，买入时锁定；可能为负，到期时可能少于本金，最多亏光本金；指数行情从国内公开行情接口取，取不到时由银行管理员登记；可随时按当时净值赎回，到期自动转回活期 |
| 贷款 | 办理与还款 | 柜台当场放款，不设审批，额度按信用分；分期（等额本金）或一次还清，最长 8 周，学期内和假期都能办，可以跨学期；放款、还款都可走账户或现金；按天计息 |
| 贷款 | 逾期 | 应还日自动扣款，余额不足即逾期：标红、罚息、扣信用分、结清前不能再贷款 |
| 柜台 | 轧账 | 上班登记备用金，下班总结按面额列出收入、付出、应有，柜员录入实点，财务或银行管理员复核；不平写明原因 |
| 管理 | 风险提醒 | 大额贷款、大额取款、提前支取、冲正与频繁操作、参数与信用分修改、库存不足、轧账不平、手动补录与更正、信用分开关；行长可以查看，由银行管理员处理（标为已查看或事后终止） |
| 货币发行 | 发行、回收、销毁与监控 | 从上线起登记；纸币与电子币分开监控，提示兑付能力 |
| 文创商城 | 库存预警 | 低于安全库存时在总览和风险提醒里提示 |
| 报表 | 经营看板 | 账户余额、银行应有现金、贷款余额、文创库存、本周业务笔数、本周锚点，按周业务柱状图，风险提醒 |
| 报表 | 报表导出 | 日 / 周 / 月流水导出为 Excel，字段与现有台账一致 |
| 学期 | 学期结转 | 银行管理员登记学期起止；学期末结转，余额、信用分和未结的定期、理财、贷款转入下学期，历史数据按学期查看；计息、锚点、信用分、贷款都不区分学期内和假期 |
| 系统 | 工作人员导入 | 像名册一样批量创建工作账号、为柜员绑定工资账户；所有创建账号和重置密码的操作都出通知单 |
| 系统 | 手动补录与更正流水 | 系统故障等情况下的备用方案，只有银行管理员能用：补录存款、取款、兑换或调账，记在原始发生时间（不早于这位学生开户，不限学期），之后已算过的活期利息随之更正；「编辑」一笔流水时，系统冲正原流水并按改好的内容生成新流水，两笔互相关联、原流水保留；每笔都写原因、二次确认、记日志 |
| 系统 | 考勤与工资 | 柜员、财务、库管、行长可以绑定学生账户、参与考勤；柜员按柜台上班、下班自动记，其他身份在本人的工作账号上签到，都由银行管理员审查；行长、银行管理员在考勤表里直接点格子为别人签到（补签），即时有效；工资按身份和班次分别设定 |
| 公开页面 | 利率看板 | 不用登录，五块大小不一的拼块大字显示活期（所有学生相同）、贷款（600～1000 分）、定期的周利率，以及理财参考指数当天的涨跌和各档当天的收益，每分钟自动更新，用于大屏 |
| 公开页面 | 大屏时间 | 不用登录，大字显示精确到秒的时间，以服务器时间为准 |
| 公开页面 | 文件传输 | 不用登录，一次上传多个文件，得到 4 位取件码，7 天内凭码反复下载，到期自动删除；限制大小和次数，银行管理员可以提前删除 |

### 5.3 关键用户故事

- 作为同学，我想在柜台借一笔小额贷款买文创，并知道什么时候要还多少、利息多少。
- 作为同学，我想看到自己的信用分为什么涨、为什么跌，好好存钱、按时还款就能借得更多、利息更低。
- 作为同学，我想把活期的钱转成定期，到期拿到更多利息。
- 作为同学，我想用一部分钱买理财，看它跟着市场涨跌，学会投资有风险。
- 作为财务、库管或行长，我想和柜员一样记考勤、领工资。
- 作为柜员，我想下班时看到每种面额应该有几张，数一遍储蓄盒就知道对不对。
- 作为财务，我想复核每位柜员的储蓄盒，并按周、按月导出和原来台账一样格式的流水。
- 作为银行管理员，我想及时看到大额贷款、频繁冲正这类风险，必要时马上终止。
- 作为银行管理员，我想打开看板就知道存款、现金、贷款和流通的海豚币是否健康。
- 作为银行管理员，我想学期末一键结转，以前的数据还能查。
- 作为海豚银行，我想在大厅的大屏上显示本周利率和准确的时间。
- 作为老师或同学，我想不用登录就把几个文件传到另一台电脑上，凭 4 位数取出来。

### 5.5 本阶段不包含

- 胸卡扫码、凭条打印、盘点、商品条码 → 暂不做
- 存折业务（新办、补办、销户）→ 暂不做；销户由银行管理员注销
- 对公业务、积分转海豚币、兑换扣闪光点 → 以后再定
- 家长端、教师端 → 阶段三

## 6. 阶段三：延伸到智慧校园与理财

### 6.1 阶段目标

- 家长和老师通过智慧校园手机端参与：家长看得到、老师管得到。
- 学部、级部、学生处与班级之间的海豚币往来（对公业务）在系统中完成。
- 引入存折、利息、定期理财和积分转海豚币，让校园银行更接近真实银行。

### 6.2 功能范围

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 家长端 | 账务查询 | 家长查看孩子的余额与交易记录 |
| 家长端 | 预约办理 | 预约到柜台办理业务的时间 |
| 家长端 | 变动通知 | 孩子账务有变化时即时通知家长 |
| 教师端 | 班级海豚币管理 | 班主任 / 科任老师对本班学生发放、奖励、扣除海豚币 |
| 教师端 | 社团管理 | 社团老师管理社团学生，发放工资 |
| 教师端 | 查询与报表 | 查询所有学生账务，查看各类报表 |
| 对公业务 | 机构间往来 | 学生处与班级、学部与级部和班级之间的海豚币发放、奖励、回收 |
| 存折 | 新办 / 补办 / 销户 | 开户时登记新存折；补办需交工本费（第一次 2 HTB，第二次 4 HTB，以此递增）；毕业等情况销户并注销账号 |
| 理财 | 活期 / 定期与利息 | 已提前到阶段二（5.2） |
| 贷款 | 资格与利率 | 已提前到阶段二，改由海豚信用分决定，不结合班优（5.2） |
| 贷款 | 逾期管理 | 已提前到阶段二（5.2） |
| 积分 | 积分转海豚币 | 线上积分按比例（如 10:1，待定）转为海豚币 |
| 账户 | 冻结 / 挂失 | 银行管理员操作，冻结后禁止交易 |
| 货币发行 | 回收与销毁登记 | 已提前到阶段二（5.2） |
| 文创商城 | 扫码入库与下架 | 扫商品条码读取信息方便入库；文创不达标等情况可提前下架 |
| 柜台 | 兑换确认 | 领取商品后进行「确认交易」，并同步扣减闪光点 |

### 6.3 关键用户故事

- 作为家长，我想在手机上看到孩子每一笔海豚币的变化，这样能和孩子聊聊怎么花钱、怎么存钱。
- 作为家长，我想预约孩子去柜台办业务的时间，避免排队。
- 作为班主任，我想在手机上给表现好的同学发放奖励，海豚币直接进入他的账户。
- 作为社团老师，我想给社团同学发工资，不用再统计后交给银行。
- 作为学生处老师，我想把海豚币拨给各班，各班的收支都有记录。
- 作为学生，我想把活期的钱转成定期，到期拿到更多利息。
- 作为学生，我想把线上积分换成海豚币。
- 作为丢了存折的同学，我想补办一本新存折，并清楚要交多少工本费。

### 6.4 验收标准

- [ ] 孩子账务变动后，家长端即时收到通知，内容与柜台记录一致。
- [ ] 教师端只能管理本人任教班级或社团的学生，发放、奖励、扣除均留有记录。
- [ ] 对公往来的每一笔都能看到拨出方、接收方、金额、用途。
- [ ] 定期存款到期后按对应利率自动计息，学生可查看利息明细。
- [ ] 补办存折的工本费按补办次数递增收取。
- [ ] 逾期贷款自动标红，该生无法再提交新申请，直到结清。
- [ ] 冻结的账户无法办理任何交易，解冻后恢复。
- [ ] 积分转换按设定比例执行，转换记录可查。

## 9. 隐私与安全承诺（产品层面）

- 不采集学生身份证号、家庭住址；家长端只展示与本人孩子相关的信息。
- 新账号与重置后的密码为默认密码，首次登录后本人设置一次新密码（至少 8 位，须同时包含英文字母和数字），之后只能由银行管理员或运维员重置；任何人都不能直接修改余额或删除记录。
- 所有操作都记录操作人和时间，银行管理员可随时审计。
- 每日自动备份，每学期至少演练一次恢复。
- 利率看板、大屏时间和文件传输不需要登录，不显示任何学生或工作人员的信息；上传的文件 7 天后自动删除。
