## 1. 产品概述

### 1.1 背景与问题

海豚银行是明德学校面向学生的校园银行，学生以海豚币办理存取、兑换文创和贷款，由学生社员担任柜员、会计、库管、行长，指导老师负责管理。目前账本是一张 Excel 表，靠公式计算存入、取出和利息，带来以下问题：

- **容易出错**：柜员手工录入、手工算钱，四年级学生输错学号、算错找零的情况难以避免。
- **难以对账**：每班次结束时无法快速核对储蓄盒现金与账面是否一致，差错难以追溯到人和时间。
- **缺少约束**：表格里余额可以直接改、记录可以直接删，透支、超卖、重复记账没有硬性拦截。
- **信息不透明**：学生、老师、家长无法随时查看账户情况，库存、发行量、贷款等经营数据要靠人工统计。

### 1.2 产品定位

一个让小学生也能准确、轻松办理业务的**校园银行业务平台**：柜台办业务、后台管经营、老师管货币与审批，并逐步延伸到智慧校园的家长端和教师端。

### 1.3 产品原则

1. **账永远对得上**：余额只能由业务流水推出，错账用冲正更正，记录不删除；每班次都要轧账。
2. **办理与审批分离**：柜员能发起，不能批准；每个角色只做自己权限内的事。
3. **孩子用得会**：大按钮、少层级、说孩子听得懂的话，界面文字与《柜台业务 SOP 卡片》一致。
4. **纸质兜底**：凭条留存、离线可登记，系统故障时业务不中断、记录不丢失。

## 3. 分阶段总览

| 阶段 | 主题 | 一句话目标 | 主要使用者 |
| --- | --- | --- | --- |
| **阶段一** | 柜台上线，替代 Excel 账本 | 日常存、取、兑换全部在系统中完成，每班次能当场轧平账 | 柜员、会计、库管、指导老师、学生 |
| **阶段二** | 完善运营与管理 | 贷款、冲正、盘点、发行监控、报表都有完整流程，老师随时看得到经营全貌 | 新增行长；会计与老师用得更深 |
| **阶段三** | 延伸到智慧校园与理财 | 家长、班主任、社团老师通过手机参与；引入存折、利息、定期理财、积分兑换 | 新增家长、各类教师 |

各阶段上线前提：前一阶段已稳定运行至少一个完整月，且轧账平账率达到该阶段目标（见第 7 节）。

## 4. 阶段一：柜台上线，替代 Excel 账本

### 4.1 阶段目标

- 柜台日常业务（存款、取款、兑换文创）全部在系统中办理，停用 Excel 账本。
- 每个班次结束时都能完成轧账，差额可当场逐笔核查。
- 学生能自助查到自己的余额和最近交易。

### 4.2 功能范围

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 账户 | 批量开户 / 导入名册 | 老师导入学生名册后自动为每位学生开户，初始余额为 0；支持把现有 Excel 账本的余额迁入 |
| 账户 | 身份识别 | 以二维码胸卡扫码为主，学号 + 密码为辅 |
| 账户 | 学生查询 | 余额、交易明细、存款排名（可匿名） |
| 柜台 | 存款 | 按面额（1/2/5/10 元）录入张数，自动算总额 |
| 柜台 | 取款 | 余额不足禁止提交；自动给出配钞方案 |
| 柜台 | 兑换 / 购买文创 | 显示商品与实时库存，结算时显示应付、余额、找零；扣款、扣库存、记账同时完成 |
| 文创商城 | 商品管理 | 商品名称、图片、价格、上架状态 |
| 货币发行 | 发行登记 | 登记批次、面额与张数、用途、审批人 |
| 对账 | 日终轧账 | 系统汇总当班收付，会计录入实物清点，自动比对；平账后锁定班次 |
| 系统 | 用户、角色、权限 | 按角色授权，所有操作留痕 |
| 系统 | 数据备份与恢复 | 每日自动备份，可一键恢复 |
| 系统 | 离线登记 | 断网时柜台可暂存业务，恢复后补传；配合纸质单据兜底 |

### 4.3 关键用户故事

**柜员**
- 作为当班柜员，我想扫一下同学的胸卡就看到他的姓名、班级和余额，这样不用让同学报学号，也不会办错人。
- 作为当班柜员，我想按面额输入收到的张数，由系统算出总额，这样不用心算，也不会算错。
- 作为当班柜员，我想在取款时看到「10 元 × 2 张、5 元 × 1 张」这样的配钞提示，这样能快速配好钱。
- 作为当班柜员，我想在同学余额不够时被系统直接拦住，这样不会出现透支。

**会计**
- 作为复核会计，我想在班次结束时录入储蓄盒里各面额的张数，让系统告诉我平不平，这样几分钟内就能完成轧账。
- 作为复核会计，我想在账不平时看到差额和当班每一笔流水，这样能逐笔找到问题。

**学生**
- 作为学生，我想扫码就能看到自己有多少海豚币和最近的交易，这样我清楚自己的钱去哪了。

**库管 / 指导老师**
- 作为库管，我想上架新文创并设置价格和图片，这样柜台马上就能兑换。
- 作为指导老师，我想一次导入全校名册就完成开户，这样不用一个个建账户。
- 作为指导老师，我想登记每一批发行的海豚币，这样流通的钱都有来历。

### 4.4 业务规则（本阶段生效）

- 余额不能直接修改，只能由业务流水产生变化。
- 禁止透支：取款、消费时余额不足一律拦截。
- 最小金额单位为 1 元，所有金额为整数。
- 单笔、单日取款有限额（建议单笔 ≤ 200、单日累计 ≤ 500），由老师设置。
- 同一笔业务重复提交只记一次账。
- 库存为 0 的商品不可兑换；同时抢购时后到者提示「已售罄」。
- 流水不可删除；班次轧账后不可再改，需老师解锁。

### 4.5 验收标准

- [ ] 柜员在柜台主界面一屏内能看到存款、取款、购买、查询入口，任何业务点击不超过 2 层。
- [ ] 余额不足时，取款和兑换无法提交，并提示「余额不够啦，你还有 X 元」。
- [ ] 兑换成功后，学生余额、商品库存、交易记录三者同时更新；任一项失败则三者都不变。
- [ ] 存款、取款、兑换成功后显示大字结果，如「存入 15 元，你的余额是 43 元」。
- [ ] 会计录入清点结果后，系统立即显示平账或差额；平账后该班次记录无法修改。
- [ ] 老师次日打开后台能看到「昨日轧账状态」，未轧账班次标红。
- [ ] 断网时柜台仍可登记业务，恢复网络后可一键补传，补传后账目与纸质凭条一致。
- [ ] 学生扫码 2 秒内看到余额和最近 10 笔交易。
- [ ] 现有 Excel 账本余额迁入后，与原账本逐人核对一致。

### 4.6 本阶段不包含

- 贷款、冲正、凭条打印、盘点、报表导出、经营看板 → 阶段二
- 家长端、教师端、存折、利息与定期、积分转海豚币 → 阶段三

## 5. 阶段二：完善运营与管理

### 5.1 阶段目标

- 贷款从申请、审批、放款到还款全程在系统中完成。
- 办错的业务可以规范更正，错账有据可查。
- 老师和会计能随时看到经营全貌，并按日、周、月导出报表。

### 5.2 功能范围

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 柜台 | 冲正（撤销） | 柜员对当班办错的业务发起冲正，生成一笔反向记录，原记录保留并标记作废 |
| 柜台 | 凭条打印 | 打印品名、金额、余额、交易号；取款凭条请学生签字留存，兑换凭条作为取货凭证 |
| 柜台 | 还款 | 柜台主界面增加贷款、还款入口 |
| 贷款 | 申请与审批 | 柜员录入金额、用途、还款计划；有未结清贷款者不能再申请；限额内（默认 50）行长审批，超额指导老师审批 |
| 贷款 | 还款登记 | 按期登记还款，自动显示剩余本金 |
| 文创商城 | 入库与盘点 | 入库登记、盘点录入、差异说明 |
| 文创商城 | 库存预警 | 低于安全库存时提醒老师 |
| 货币发行 | 流通总量监控 | 对比发行总量与「账面余额 + 柜面现金」 |
| 教师管理 | 工资发放 | 指导老师向学生社员发放工资 |
| 报表 | 经营看板 | 存款余额、柜面现金、贷款余额、文创库存、业务笔数等 6 个核心指标，按周业务柱状图，轧账状态提醒 |
| 报表 | 报表导出 | 日 / 周 / 月流水导出为 Excel，字段与现有台账一致 |
| 学期 | 学期结转 | 学期末一键结转（余额清零或转入下学期），历史数据归档 |

### 5.3 关键用户故事

- 作为当班柜员，我想在办错一笔存款后发起冲正，这样不用涂改，记录也清清楚楚。
- 作为同学，我想申请一笔小额贷款买文创，并知道什么时候要还多少。
- 作为行长，我想在手边审批 50 元以内的贷款申请，这样同学不用等老师。
- 作为指导老师，我想只审批超额贷款，并看到每位同学的贷款和还款情况。
- 作为库管，我想登记入库和盘点结果，并在库存快没时收到提醒，这样热门文创不断货。
- 作为指导老师，我想打开看板就知道存款总额、柜面现金和流通的海豚币是否对得上。
- 作为会计，我想按周、按月导出流水，用和原来台账一样的格式上交。
- 作为指导老师，我想学期末一键结转，下学期从干净的账开始，以前的数据还能查。

### 5.4 验收标准

- [ ] 冲正只能针对当班业务；冲正后余额恢复，原记录仍可见并标记作废。
- [ ] 有未结清贷款的学生，柜员无法再提交新的贷款申请。
- [ ] 50 元以内的申请只出现在行长待办里，超过 50 元的只出现在指导老师待办里；审批人与申请录入人不能是同一人。
- [ ] 贷款批准后，学生余额与贷款本金同时增加；每次还款后剩余本金自动更新。
- [ ] 库存低于安全库存时，老师在后台收到提醒。
- [ ] 看板上「发行总量」与「账面余额 + 柜面现金」不一致时有醒目提示。
- [ ] 导出的 Excel 可直接替代原有台账使用。
- [ ] 学期结转后，上学期数据只读可查。

### 5.5 本阶段不包含

- 逾期自动标红与暂停申请、账户冻结与挂失、旧币回收与销毁登记 → 阶段三
- 家长端、教师端、存折、利息与定期 → 阶段三

## 6. 阶段三：延伸到智慧校园与理财

### 6.1 阶段目标

- 家长和老师通过智慧校园手机端参与：家长看得到、老师管得到。
- 学部、级部、学生处与班级之间的海豚币往来（对公业务）在系统中完成。
- 引入存折、利息、定期理财和积分转海豚币，让校园银行更接近真实银行。

### 6.2 功能范围

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 家长端 | 账务查询 | 家长查看孩子的余额与交易记录 |
| 家长端 | 预约办理 | 预约到柜台办理业务的时间 |
| 家长端 | 变动通知 | 孩子账务有变化时即时通知家长 |
| 教师端 | 班级海豚币管理 | 班主任 / 科任老师对本班学生发放、奖励、扣除海豚币 |
| 教师端 | 社团管理 | 社团老师管理社团学生，发放工资 |
| 教师端 | 查询与报表 | 查询所有学生账务，查看各类报表 |
| 对公业务 | 机构间往来 | 学生处与班级、学部与级部和班级之间的海豚币发放、奖励、回收 |
| 存折 | 新办 / 补办 / 销户 | 开户时登记新存折；补办需交工本费（第一次 2 HTB，第二次 4 HTB，以此递增）；毕业等情况销户并注销账号 |
| 理财 | 活期 / 定期与利息 | 存款分活期和定期，定期按存期适用不同利率；可将活期部分或全部转为定期；系统自动计息 |
| 贷款 | 资格与利率 | 结合班优记录，无不良记录者可申请；系统计算贷款利率 |
| 贷款 | 逾期管理 | 逾期自动标红，暂停该生新的贷款申请 |
| 积分 | 积分转海豚币 | 线上积分按比例（如 10:1，待定）转为海豚币 |
| 账户 | 冻结 / 挂失 | 老师操作，冻结后禁止交易 |
| 货币发行 | 回收与销毁登记 | 旧版回收、损毁币种登记 |
| 文创商城 | 扫码入库与下架 | 扫商品条码读取信息方便入库；文创不达标等情况可提前下架 |
| 柜台 | 兑换确认 | 领取商品后进行「确认交易」，并同步扣减闪光点 |

### 6.3 关键用户故事

- 作为家长，我想在手机上看到孩子每一笔海豚币的变化，这样能和孩子聊聊怎么花钱、怎么存钱。
- 作为家长，我想预约孩子去柜台办业务的时间，避免排队。
- 作为班主任，我想在手机上给表现好的同学发放奖励，海豚币直接进入他的账户。
- 作为社团老师，我想给社团同学发工资，不用再统计后交给银行。
- 作为学生处老师，我想把海豚币拨给各班，各班的收支都有记录。
- 作为学生，我想把活期的钱转成定期，到期拿到更多利息。
- 作为学生，我想把线上积分换成海豚币。
- 作为丢了存折的同学，我想补办一本新存折，并清楚要交多少工本费。

### 6.4 验收标准

- [ ] 孩子账务变动后，家长端即时收到通知，内容与柜台记录一致。
- [ ] 教师端只能管理本人任教班级或社团的学生，发放、奖励、扣除均留有记录。
- [ ] 对公往来的每一笔都能看到拨出方、接收方、金额、用途。
- [ ] 定期存款到期后按对应利率自动计息，学生可查看利息明细。
- [ ] 补办存折的工本费按补办次数递增收取。
- [ ] 逾期贷款自动标红，该生无法再提交新申请，直到结清。
- [ ] 冻结的账户无法办理任何交易，解冻后恢复。
- [ ] 积分转换按设定比例执行，转换记录可查。

## 7. 成功指标

以下目标为建议值，上线前由指导老师确认。

| 指标 | 衡量方式 | 阶段一目标 | 阶段二目标 | 阶段三目标 |
| --- | --- | --- | --- | --- |
| 系统办理覆盖率 | 系统内办理的业务笔数 / 全部业务笔数 | 存取兑换 100% | 含贷款、冲正 100% | 含对公、理财 100% |
| 当场轧平率 | 当天轧账即平账的班次 / 全部班次 | ≥ 90% | ≥ 95% | ≥ 98% |
| 单笔办理时长 | 柜员从识别身份到办完一笔的时间 | ≤ 1 分钟 | ≤ 1 分钟 | ≤ 1 分钟 |
| 差错可追溯率 | 能定位到具体人和时间的差额 / 全部差额 | 100% | 100% | 100% |

## 9. 隐私与安全承诺（产品层面）

- 不采集学生身份证号、家庭住址；家长端只展示与本人孩子相关的信息。
- 学生密码只有本人可修改；任何人都不能直接修改余额或删除记录。
- 所有操作都记录操作人和时间，老师可随时审计。
- 每日自动备份，每学期至少演练一次恢复。
