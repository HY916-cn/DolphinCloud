# 海豚云发布会 · 脚本

发布会主题 **It all adds up.**（每一笔，都算数。）

| 项目 | 约定 |
| --- | --- |
| 总长 | 约 12 分钟 |
| 画幅 | 16:9，成片 3840×2160，30 fps |
| 实拍 | 4K 30 fps 横拍；慢镜头用 4K 60 fps；用相机或手机拍摄，由主讲人完成 |
| 语言 | 中文为主，英文适量：台词讲中文；Good morning、主题 “It all adds up.” 保留英文；章节大字配一行小号英文（如“柜台 Counter”）；全片加中文字幕 |
| 视觉 | 海豚云设计系统（`design-system/project/`）：海豚蓝、云朵色、三层海浪、大圆角、Nunito Sans + 思源黑体 |
| 背景 | 苹果发布会式的简洁画面：以纯白背景为主；需要压暗、制造悬念的地方用纯黑背景，如开场片的悬念与安静、One more thing |
| 文字颜色 | 按内容动态搭配，不全用一种颜色：大标题和正文用深色 `ink`，要强调的词和数字用海豚蓝 `dolphin`；讲到某类业务时用它的类别色（存款海青、取款与贷款葡萄紫、兑换珊瑚粉、奖励与利息金色）；涨跌用红涨绿跌；黑底上用白字配海豚蓝或金色点缀 |
| 节奏 | 跟着音乐卡点，硬切为主，越往后越快 |
| 呈现 | 3D、有层次：设备和界面卡片悬浮在三维空间里，前后错开、轻微倾斜，带景深和厚底阴影；镜头慢推、环绕，见“呈现方式” |
| 演示数据 | 只用本地种子数据（王小雨、柜员小林、王行长等测试账号），不录正式服务器；各段的真实页面截图在 `docs/launch/storyboard/` |

## 呈现方式

演示和字卡都用真实的海豚云界面，按下面的方式做出 3D 的层次感。动作克制、慢、稳；界面本身的动效仍按 `motion.md`。

| 手法 | 做法 | 用在 |
| --- | --- | --- |
| 设备悬浮 | 平板、手机、笔记本、大屏放在纯色背景里，轻微倾斜（10°～20°），缓慢转正，地面有柔和的投影 | 每段演示的开头 |
| 界面分层 | 讲到的界面元素从屏幕里浮出成独立的一层，前后错开、带景深：存款时人员卡、面额卡、办理单三层；轧账时每种面额一层 | 演示 1～6、10、13 |
| 错落排列 | 多台设备前后错开摆放，镜头环绕或推拉，近处清楚、远处虚化 | 演示 7 三设备并排、功能墙、回顾短片 |
| 卡片空间 | 余额卡、宫格、按钮、面额卡等真实组件以卡片悬浮在空中，镜头从层间穿过 | 设计短片、功能墙、数字页 |
| 海浪纵深 | 三层海浪前后分开，各自以不同速度移动，形成视差 | 标题、大屏、结尾 |
| 推近标注 | 镜头推近到要讲的数字或按钮，旁边出现一个设计系统样式的圈或箭头和一句中文说明 | 所有演示 |

## 三 · 柜台（2:45–5:00）· 柜员
