# BP-017 Notices

- 当前实现：`client/src/components/Notices.tsx`（通知单与期初核对表）
- 当前契约：Notices 的既有职责、接口与调用方；详细实例见下表。

## 目标契约

| 维度 | 具体内容 |
|---|---|
| 职责 | Notices的职责与边界，详见当前契约。 |
| 接口 | 保留现有 props/回调；新增状态以可选参数或内部状态实现，避免破坏调用方。 |
| 状态 | 覆盖加载、空、错误、成功、禁用、权限不足与中断恢复。 |
| 数据副作用 | 权威数据来自 Supabase/RPC；缓存与本地状态需可失效，失败保留可恢复路径。 |
| 语义/可访问性 | 正式凭证日期统一 Asia/Shanghai；长姓名/班级需换行。 |
| 样式布局 | 使用设计 token；桌面/手机无横向溢出；动效尊重 reduced-motion。 |
| 性能生命周期 | 大批量通知单必须分批生成/释放 canvas；内存与时间有预算。 |
| 安全隐私 | 只展示/提交被授权字段；权限以服务端为准，前端守卫只做导航。 |
| 可观测性 | 错误以用户可读中文呈现；不记录令牌/完整敏感数据。 |
| 集成 | 保持父子页面契约；变更需同步页面、测试与验收场景。 |
