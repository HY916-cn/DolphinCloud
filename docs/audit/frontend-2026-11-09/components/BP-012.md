## 目标契约

| 维度 | 具体内容 |
|---|---|
| 职责 | Duty的职责与边界，详见当前契约。 |
| 接口 | 保留现有 props/回调；新增状态以可选参数或内部状态实现，避免破坏调用方。 |
| 状态 | 离线不得被未上班闸门阻断；上班按钮仅在线可用。 |
| 数据副作用 | 权威数据来自 Supabase/RPC；缓存与本地状态需可失效，失败保留可恢复路径。 |
| 语义/可访问性 | 保持可访问名称、role、键盘与焦点；动态结果用 status/alert 宣告。 |
| 样式布局 | 使用设计 token；桌面/手机无横向溢出；动效尊重 reduced-motion。 |
| 性能生命周期 | 避免重复请求与无界内存；卸载清理监听/对象 URL/计时器。 |
| 安全隐私 | 只展示/提交被授权字段；权限以服务端为准，前端守卫只做导航。 |
| 可观测性 | 错误以用户可读中文呈现；不记录令牌/完整敏感数据。 |
| 集成 | 保持父子页面契约；变更需同步页面、测试与验收场景。 |
