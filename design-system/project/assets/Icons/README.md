# Icons

海豚云业务图标：48×48 网格，3px 圆头描边 `dolphin`，填充 `cloud-200`（浅蓝）和 `coin`（金色）两种。成功、警示两个图标分别用 `success` / `danger` 的线色和浅底。

- 业务：`deposit` 存款、`withdraw` 取款、`exchange` 兑换、`query` 查询、`invest` 理财、`loan` 贷款、`transfer` 转账、`passbook` 存折、`calendar` 预约。
- 账户与人物：`coin` 海豚币、`star` 奖励/闪光点、`me` 我的、`parent` 家长、`teacher` 老师、`lock` 密码。
- 导航与反馈：`home` 首页、`bell` 消息、`help` 帮助、`success` 成功、`warning` 警示。
- 用 `<img class="dc-icon">` 引用，常用尺寸 20 / 24 / 32 / 36 / 56px；图标颜色已经画在文件里，放在 `surface`、`surface-raised`、`cloud-100` 上。放在 `dolphin` 实心底上时（主按钮）要垫白色圆底。
- 图标总是和文字一起出现，除非是头像或纯装饰。
