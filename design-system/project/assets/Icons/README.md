# Icons

海豚云业务图标，Phosphor Icons Duotone 风格（MIT 许可）：256 网格，实色线条 + 同色 20% 透明度填充。墨色画在文件里：业务图标为 `dolphin`（#1f5ff5），`success` 为 `success`（#0b6e4c），`warning` 为 `danger`（#b23c0a）。

- 业务：`deposit` 存款、`withdraw` 取款、`savings` 储蓄、`exchange` 兑换、`query` 查询、`invest` 理财、`loan` 贷款、`transfer` 转账、`passbook` 存折、`calendar` 预约。
- 账户与人物：`coin` 海豚币、`star` 奖励 / 闪光点、`me` 我的、`parent` 家长、`teacher` 老师、`lock` 密码。
- 导航与反馈：`home` 首页、`bell` 消息、`help` 帮助、`success` 成功、`warning` 警示。
- 组件里内联同一份路径并改为 `fill="currentColor"`，让图标跟随文字颜色；作为 `<img>` 使用时放在 `surface`、`surface-raised`、`cloud-100` 上。
- 常用尺寸 20 / 26 / 30 / 36 / 52px。图标总是和文字一起出现，除非是头像或纯装饰。
