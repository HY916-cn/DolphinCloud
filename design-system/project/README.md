海豚云是明德实验学校海豚银行的线上系统。主要使用者是小学生：他们在这里查余额、存取海豚币、兑换文创、学着理财。界面以**云朵、海浪、海豚**为元素，海豚蓝为主色，页面始终明亮、圆润、好按。

## 设计原则

1. **孩子一眼看得懂。** 每屏只办一件事；业务入口用大图标 + 两个字；金额是全页最大的字。
2. **每一步都有人带。** 新功能用“小海豚提示”（`GuideBubble`）带着走，办理业务用 `Steps` 显示进度，结果用 `Notice` 说清楚。
3. **软软的、能按下去。** 所有可点的东西都是大圆角和厚底阴影，按下会下沉，像积木一样。
4. **账永远对得上。** 金额用 `amount` 样式写清楚，收支总配文字（存入 / 支出），不只靠颜色。

## 文字与语气

- 用“你”称呼孩子，句子短，一句话说一件事。可以在句末用“哦”“吧”“啦”，不用感叹号堆砌（一句最多一个）。
- 说孩子听得懂的话，和《柜台业务 SOP 卡片》一致：“存进去”“取出来”“查一查”，不说“提交”“申请处理”“操作成功”。
- 出错时说发生了什么、接下来怎么办：“余额只有 1,280 HTB，换个小一点的数字吧”。不用“错误”“失败”“非法”“异常”。
- 海豚币单位写 `HTB`，金额用千分位逗号：`1,280 HTB`。收入写 `+50`，支出写 `−20`（用减号 −）。
- 时间写“10月27日 14:20”。按钮文字 2～5 个字，动词开头。
- 不用 emoji 当图标，用 Icons 组里的图标。

## 颜色

- 页面底色 `surface`，卡片和输入框 `surface-raised`。浅蓝 `cloud-100` 用于余额卡、选中态、引导气泡等“被强调的区域”。
- `dolphin`（#1f5ff5，取自 logo 的海豚）是唯一的主色：主按钮、选中导航、图标线条、链接。按下和焦点用 `dolphin-deep`；`dolphin` 上的文字用 `on-dolphin`。
- 云朵色阶 `cloud-100` → `cloud-500` 取自 logo 的五层海浪，只用于背景、海浪和图标填充，`cloud-300` 及更深不放文字。
- 文字：标题正文 `ink`，次要信息 `ink-muted`。`cloud-100` / `cloud-200` 上的蓝色文字用 `dolphin-deep`。
- 海豚币用金色 `coin`（图标、星星），金币相关文字用 `coin-ink` 放在 `coin-soft` 上。
- 状态：`success` / `success-soft` 表示成功到账，`danger` / `danger-soft` 表示没办成或要注意。两者亮度相近，所以**永远配图标和文字**（`success` / `warning` 图标）。
- 所有文字与底色的组合 ≥ 4.5:1，边框、焦点环、图标 ≥ 3:1；每个颜色的 usage 写明了它能放在哪些底色上。

## 字体

- 标题字体 `display`：站酷快乐体（ZCOOL KuaiLe），只用于 `display`（首页欢迎语、成功页）和 `title`（页面标题）。
- 其余全部用 `sans`：Nunito 负责数字和字母（圆润），中文落到思源黑体（Noto Sans SC）/ 苹方 / 微软雅黑。
- 字号：`amount` 44px 用于余额与金额；`heading` 22px 卡片标题；`body-lg` 20px 按钮、入口名称、引导语；`body` 17px 正文，是界面里最小的正文；`caption` 14px 只用于时间、单位、标签。
- 正文字重 500，标题 800；不用 400 以下的细字。

## 形状：云、浪、海豚

- **圆角很大**：标签 `radius-sm`（12px），输入框、提示条 `radius-md`（20px），卡片、宫格、弹层 `radius-lg`（28px），按钮和胶囊 `radius-pill`。界面里没有直角。
- **海浪**是连续的缓曲线，三层由浅到深（`cloud-200` → `cloud-400`），用 `WaveDivider` 收尾卡片或头图，每屏最多两处，海浪上不放内容。
- **云朵**：大块的 `cloud-100` 圆角区域承载重点信息（余额、引导），像一朵云托着内容。
- **海豚**只以 logo 的形式出现：登录页、引导气泡头像。不另画海豚插图，不改变 logo。

## 阴影与状态

- 卡片和宫格用 `shadow-card`：向下 6px 的实色“厚底”，不用灰色模糊阴影。主按钮用 `shadow-button`（`dolphin-deep` 厚底）。
- 浮在页面上的东西（弹层、引导气泡、底部导航）用 `shadow-float`。
- 按下：元素下移 3～4px，厚底变薄。禁用：`cloud-200` 底 + `ink-muted` 字，并在按钮上写原因。
- 键盘焦点：`focus-ring`（一圈白 + 一圈 `dolphin-deep`），所有可点元素都有。
- 动效短而轻（100～200ms），只用于按下、出现和数字变化；不做闪烁和长时间循环动画。

## 布局与触控

- 间距用 `space-1` 到 `space-7`（4 → 48px）。卡片内边距 `space-5`，页面分区间距 `space-6`，手机端左右留白 `space-4`。
- 可点区域最小 44×44px，主要按钮 56px 高；相邻可点元素至少相隔 `space-3`。
- 电脑终端（柜台）：内容区最宽 1080px，业务宫格一行 4 个。手机终端（家长端、学生端）：单列，底部 `TabBar`。
- 一屏一个主按钮，放在内容下方、拇指够得到的位置。

## 图标

- 使用 Icons 组的 20 个业务图标：48×48 网格、3px 圆头描边 `dolphin`、`cloud-200` 浅蓝填充，与金币相关的部分用 `coin` 金色。
- 图标总是和文字一起出现（头像和纯装饰除外）。常用尺寸：标签 20px、按钮 28px、导航 32px、提示条 36px、宫格 56px。
- 图标是 `<img>`，颜色已画在文件里：放在 `surface`、`surface-raised`、`cloud-100` 上；放在 `dolphin` 实心底上时垫白色圆底（主按钮已内置）。
- 需要新图标时按同一网格和描边画，填充只用 `cloud-200` 和 `coin`。

## 组件

组件是纯 CSS 类（`components/bundle.css`，前缀 `dc-`），在任意框架里写对应的 HTML 结构即可使用：`Button`、`ServiceTile`、`BalanceCard`、`TxnList`、`GuideBubble`、`Steps`、`Field`、`Tag`、`Notice`、`TabBar`、`WaveDivider`。每个组件的 README 写明结构、何时使用以及使用者需要提供什么。
