# BalanceCard

余额卡：首页最显眼的一块，让学生一眼看到“我有多少海豚币”。

- 纯 `dolphin` 底，底部三层 `dc-waves` 海浪改为同色浅一层（白色 12% 叠加），不用云朵色，圆角 `radius-lg`。卡内文字一律 `on-dolphin`（≥5.2:1）。
- 标题行：白色 `coin` 图标 + “我的海豚币”（`heading`）。
- 金额用 `amount` 样式（Nunito Sans 800，40px，等宽数字），千分位逗号，单位 `HTB` 跟在后面。
- 下方 `dc-balance-split` 列出活期、定期、利息，每项是 `dolphin-deep` 胶囊（白字 7.8:1）。整张卡只有海豚蓝的深浅和白色，不加金色、渐变、光斑或其他色系；金色的币图标只放在浅色底上。

- 海平面样式 `has-tide`：卡底的海浪换成 `dc-tide`，海面的高低就是本学期余额走势（阶梯线：只有办理业务时余额才变），`dolphin-deep` 实色，零点在卡底；两端在海里写起点和今天（“9月1日 190”“今天 415”），整块加 `role="img"` 和一句完整的 `aria-label`。胶囊可改为本学期存入和支出。

使用者提供：总余额、活期/定期/利息三项数字；海平面样式另需本学期每一笔余额变动。金额永远是整数海豚币；负数不会出现在这里。一页只放一张余额卡。

动效：随页面以 `dc-enter` 进入；余额变化时用 `data-from` / `data-count` 从旧值滚动到新值（600ms）。
