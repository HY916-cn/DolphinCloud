# BalanceCard

余额卡：首页最显眼的一块，告诉孩子“我有多少海豚币”。

- 底色 `cloud-100`，底部三层 `dc-waves` 海浪，圆角 `radius-lg`。
- 标题行：`coin` 图标 + “我的海豚币”（`heading`）。
- 金额用 `amount` 样式（Nunito 800，44px），千分位逗号，单位 `HTB` 跟在后面用 `ink-muted`。
- 下方 `dc-balance-split` 列出活期、定期、利息，每项是白色胶囊。

使用者提供：总余额、活期/定期/利息三项数字。金额永远是整数海豚币；负数不会出现在这里。一页只放一张余额卡。
