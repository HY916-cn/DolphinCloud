# ColorRoles

颜色用途：海豚云的每种颜色只表示一件事。选颜色前先判断它是**操作**、**类别**还是**状态**。

- **操作**：海豚蓝 `dolphin`。主按钮、链接、选中的导航、焦点环；只有它表示“可以点、去办理”。
- **类别**：按“钱怎么动”分四类，各用一个类名，加在组件或它的容器上：
  - `dc-kind-save` 海青：储蓄（存款、储蓄、定期、储蓄目标）。
  - `dc-kind-withdraw` 葡萄紫：支取（取款、转账、贷款）。
  - `dc-kind-exchange` 珊瑚粉：兑换（兑换、文创好物）。
  - `dc-kind-reward` 金色：海豚币与奖励（奖励、闪光点、利息、理财、排名）。
  - 账户与服务（查询、明细、存折、预约、帮助、设置、身份）不加类，保持海豚蓝。
- **状态**：`success` 绿表示办成了、已到账；`danger` 橙红表示没办成、需要注意；白底蓝描边 `dc-tag-pending` 表示待处理。永远配图标和文字。

类别色只出现在图标底块、类别标签、进度条、面额卡、单系列图表五处，不用于按钮、导航、链接、正文和背景。大面积色块只有余额卡（纯海豚蓝）和登录页头图（海青到浅蓝）。

使用者提供：业务类型。按上表取类名，不按“好看”或“相邻不同色”挑颜色；一项业务在全站只用一种颜色。
