# ViewSwitch

页面样式：学生在“我的”里选用普通版还是存折版。只给学生，两个版本的“我的”页都有。

- 结构：`fieldset.dc-view-switch`，标题 `legend` 写“页面样式”；两个 `label.dc-view-opt`，各含一个隐藏的单选框、一张小图 `dc-view-art` 和文字 `dc-view-text`（名称加一句说明：“卡片式的页面”“一本可以翻的存折”）。
- 小图是纯 CSS 画的缩略图，不用图片：`is-normal` 是海豚蓝余额卡、下面一张卡片、右边一列列表；`is-book` 是一本摊开的小存折，深蓝封皮里两页纸带横线，左页一枚红章，右边缘露出四色书签。
- 选中：海豚蓝描边、`cloud-100` 底，右上角一个打勾的圆点。键盘焦点落在单选框上时整张卡出现焦点环。
- 放在存折的纸页里（`dc-pb-page` 内）时，换成纸面上的细线框、方角，选中用深蓝细线框和淡蓝底。
- 选了另一个版本就立即切换：去存折版时存折从封面翻开；从存折版回普通版时，存折先合上再离开。这台设备记住选择，下次直接打开这一版。

动效：选中时描边和底色过渡（160ms），按下下沉 2px；指向存折版那一张时，小图上的封面翻开一次（900ms）。

使用者提供：当前是哪一版。
