# StudentHomePage

学生首页示例（普通版）：登录后第一眼看到“我有多少海豚币、这学期攒了多少、在学部里排第几”。

- 外壳 `AppShell`，导航：首页、明细、信用、排名、我的；标题“下午好，林小雨”，副标题班级和学号。
- 左栏：`BalanceCard`（海豚蓝底、底部海浪），胶囊写本学期存入和支出；下面是排名卡（与 `RankingPage` 同一套 `dc-rank-*` 样式：第几名、再存多少能超过前一名、我和前后各一名，右上角“查看排名”）。
- 右栏“最近交易”（`TxnList`，9 笔，右上角“查看全部”）。
- 手机：单列，依次为余额、排名、最近交易，底部 `TabBar`；平板：左侧图标导航，单列；电脑：侧边导航，两栏。
- 示例数据自洽：上学期带入 190，本学期存入 270、支出 45，余额 415；排名第 12 名，第 11 名 428，所以还差 14。

- 信用摘要：余额卡下面一张 `dc-card dc-credit-summary`。左边 `SummaryList` 四行，右边是包在链接 `dc-credit-summary-gauge` 里的中号 `CreditGauge`（带贷款额度），点它进入“信用”页；链接的 `aria-label` 写“海豚信用分 680 分，查看信用”。
  - 三行：攒着的利息“0.37 HTB”（还没存进余额的活期利息，每周一满 1 HTB 的部分入账），金额下面 `small` 写什么时候到账：满 1.00 HTB 时“下周一存进余额”，不满时“满 1 HTB 再存进余额”；读取失败时只写“—”，没有小字；补录更正了之前的利息时可能暂时为负，写“−0.12 HTB”，小字“之前的利息有更正，之后的利息先补上这部分”（见 `ManualEntry`）；定期合计“100 HTB”（`accounts.term_total`），没有定期写“没有”；理财写现值“103.20 HTB”，下面 `small` 写盈亏（`dc-pl`，见 `Invest`），没有理财写“没有”；贷款“剩余 98 HTB”，下面 `small`“11月24日 应还 33 HTB”，没有贷款写“没有”（写法见 `Loan`）。
  - 贷款逾期时，这一行加 `is-danger`（`danger` 色），金额前加 `warning` 图标，写“已逾期 · 应还 20 HTB”，没有小字。
  - 攒着的利息和信用页的利率举例是全站仅有的精确到 0.01 HTB 的金额：总写两位小数，没有时写“0.00 HTB”；假期里照常显示。只有整数部分入账，零头留到下次，所以小字只说“存进余额”，不写到账多少。
  - 只列已经上线的项目（利息 M9、定期 M10、贷款 M11、理财 M16）。信用分暂停时仪表盘加 `is-paused`（见 `CreditGauge`）。一项都没上线时只有仪表盘，在卡片里居中。
  - 读取中：卡片里放 `Skeleton`。读取失败：卡片里放 `Notice`（`danger`）“暂时无法读取信用分”和“重试”，不显示 0 分。
  - 手机：仪表盘在上居中，各行在下；平板和电脑：各行在左，仪表盘在右。

同一个账户的存折版见 `StudentBookPage`。使用者提供：最近 9 笔交易、本学期存入和支出，以及排名接口里前一名的余额和学部人数。
