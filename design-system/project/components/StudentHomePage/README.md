# StudentHomePage

学生首页示例：登录后第一眼看到“我有多少海豚币、这学期攒了多少、在学部里排第几”。

- 外壳 `AppShell`，导航：首页、明细、排名、我的；标题行写“下午好，林小雨”，副标题班级和学号。
- 左栏：`BalanceCard` 的海平面样式（`has-tide`，卡底的海就是本学期余额走势，两端写“9月1日 190”“今天 415”），胶囊写本学期存入和支出；下面是排名卡（与 `RankingPage` 同一套 `dc-rank-*` 样式：第几名、再存多少能超过前一名、我和前后各一名，右上角“查看排名”）。
- 右栏“最近交易”（`TxnList`，9 笔，右上角“查看全部”）。电脑上两栏底边基本对齐。
- 手机：单列，依次为余额、排名、最近交易，底部 `TabBar`；平板：左侧图标导航，单列；电脑：侧边导航，两栏。
- 示例数据自洽：上学期带入 190，本学期存入 270、支出 45，余额 415；排名第 12 名，第 11 名 428，所以还差 14。

接入时需要：本学期的全部交易（画海平面）、最近 9 笔交易，以及排名接口里前一名的余额和学部人数。
