# StudentHomePage

学生首页示例：登录后看到自己摊开的存折。

- 外壳 `AppShell`，导航：首页、明细、排名、我的；标题“下午好，林小雨”，副标题“这是你的海豚云存折”。
- `Passbook`（`is-spread`）：左页“储蓄存折”写户名、账号、班级，下面是盖着银行圆章的当前余额，以及本学期存入和支出；右页“交易记录”印最近 9 笔，每笔都带变动后的余额，右上角“翻看全部”，页脚“第 1 页”。
- 存折下面是一张平面的名次卡（`dc-card dc-rank-link`）：名次徽章 `dc-medal`，“存款排名第 12 名”，以及再存多少能超过前一名；整张卡链接到排名页。
- 手机：两页上下排列，名次卡在最后，底部 `TabBar`；电脑：两页左右摊开。
- 示例数据自洽：上学期带入 190，本学期存入 270、支出 45，余额 415；每行余额依次相差该笔金额。

接入时需要：最近 9 笔交易及每笔的 `balance_after`、本学期存入和支出、排名里自己的名次和前一名的余额。
