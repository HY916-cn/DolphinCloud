# Skeleton

加载占位：数据加载时，用与真实内容同样大小的浅色块占住位置，避免页面跳动。

- 结构：`<span class="dc-skeleton" style="width:60%;height:18px">`；圆形加 `is-round`。按真实布局拼出占位，例如交易列表的一行：图标块、两行文字、金额。
- `cloud-100` 色块，透明度在 100% 和 45% 之间缓慢呼吸（1.2 秒一次）；开启“减少动态效果”时静止。
- 外层加 `aria-busy="true"` 和 `aria-label="正在加载交易"`，占位块本身对读屏隐藏。

使用者提供：与真实内容一致的占位布局。加载超过 10 秒时换成 `Notice` 说明情况。

动效：占位块透明度在 100% 和 45% 之间呼吸（1.2 秒一次）；数据到达后真实内容淡入替换占位。
