# Passbook

储蓄存折：学生的“存折版”（`StudentBookPage`）用它把整个账户印在一本存折里。这是系统里唯一按实物画的组件；普通版的学生页面和其他页面都保持平面的 DS 风格。

- 结构：`dc-passbook`（深蓝封皮，四周露出 6px）包着一页或两页 `dc-pb-page`。纸页是浅蓝底 `#f7faff` 加两层细密的防伪底纹，表头和栏线是蓝色印刷，记录用等宽字，像打印机打上去的。
- 摊开：加 `is-spread`，电脑宽度（`app` 容器 ≥1024px）左右两页并排，中缝有阴影和装订线；更窄时上下两页，接缝处是装订线。存折版里手机和平板一次只显示一页（见下面“翻页”）。
- 页头 `dc-pb-head`：字距拉开的页名（“储蓄存折”“交易记录”），下面一条双线；右侧可放 `small`（学部、当前类型）或一个链接（“翻看全部”）。
- 户名页：`dc-pb-fields` 是带格线的“户名 / 账号 / 班级”；`dc-pb-balance` 写当前余额（等宽 44px），右侧压一枚红色圆章 `dc-pb-seal`（行名沿圆周排列，中间一颗星，下面写“业务专用章”，`aria-hidden`）；`dc-pb-sums` 写本学期存入（绿色）和支出。
- 交易页：`dc-pb-table` 六栏，依次为行号、日期、摘要、支取、存入、余额。日期印成“11-03”，下面一行小字写时间，往年的记录写年份；支取和存入各占一栏，不带正负号；摘要放不下时以省略号结尾，完整内容放在 `title` 里。现金业务的支取和存入两栏都空着，摘要下面小字写“现金支付，余额不变 · 3 HTB”。没印满的一页继续印带行号的空行（`aria-hidden`）。一栏的页数是单数时，电脑上最后一组的右页是空白页 `dc-pb-page is-blank`，同样带 `data-side="right"`，页边、圆角和装订线与有字的右页相同。每页印满的行数是固定的：电脑 10 行，手机 8 行，印满就接着印在下一页，行号接着上一页往下数。页脚 `dc-pb-foot` 分三格：中间印页码“第 N 页”，左格放“上一页”、右格放“下一页”（`dc-book-flip`）。
- 封面 `dc-pb-cover`：合上的存折，在存折版里就是打开后的半本书，大小和位置都不变（电脑上高 `--book-h`、宽是摊开宽度 `--book-w` 的一半；手机和平板上和一页纸一样宽），深蓝封面上是金色的行名、标志和“储蓄存折”，下面贴一张白色标签 `dc-pb-label`。在存折版里封面就是锁（`dc-book-cover`）：标签上两行填“账号”（学号）和“密码”，下面金色的“打开存折”（`dc-book-unlock`，带锁图标）；密码不对时，标签左右轻晃，下面一张浅红纸条 `dc-book-error` 写原因。
- 打开的存折 `dc-book-open`：一本固定大小的存折，一屏放下，页面本身不滚动。高度 `--book-h`：电脑上 540–700px（随屏幕高度），宽是高的 1.44 倍；手机和平板上是整屏高（至少 500px），宽度占满。各栏目的纸页一样大，换栏目时存折不跳；万一屏幕太矮放不下，纸页自己在里面滚动。右边缘伸出四枚书签 `dc-book-mark`（账户、明细、排名、我的），竖排文字，依次用海青、金、莓红、葡萄紫四种类别浅色；当前一枚 `aria-current="page"`，拉出得更长，文字下面有一道短线。书签的文字始终露在存折外面（手机上也一样）。
- 翻页 `BookPages`：一栏可以有好几页（明细按 10 行或 8 行一页往后排；排行榜 10 名一页）。电脑上两页一组摊开，手机上一页一页看。翻页的方法：页脚的“上一页”“下一页”、在纸页上左右滑动、键盘方向键（← →）或 PageUp/PageDown。翻到还没读到的明细页时再去读更早的记录。
- 纸的质感：电脑上摊开时，左右两页的外侧边缘叠着几层纸边，看得出整本的厚度。摘要最多印两行，再多以省略号结尾。
- 翻页的纸叶 `dc-book-turning`：栏内翻页和点书签换栏目，都真的有一张纸翻过去（换栏目时纸叶用离开和到达两边印好的页面，往后面的栏目向左翻，往前面的栏目向右翻），正面是翻起的那一页，背面印着下一页（`dc-book-leaf` 里两面 `dc-book-face`，都是页面的副本，`aria-hidden`、`inert`，翻完 800ms 内收走，下面的页面才是能点的）。电脑上往后翻，右页从中缝掀起落到左边，左页上原来那一页（`dc-book-under`）等纸叶盖下来；往回翻，左页翻到右边。纸面上随翻起的角度从中缝掠过一层阴影。手机上往后翻，这一页绕左边装订线翻走，露出下一页；往回翻，上一页从左边翻回来盖上。
- 动画（只在存折版，见“动效”一节 `Passbook` 一行）：登录的封面到翻开之间不换画面（已经登录、直接打开存折版时，翻开的封面同样完整：标签上印这位学生的学号，密码一栏印 8 个圆点，只是样子，不代表密码长度）：账户信息读完之前封面一直是合着的，翻开的封面 `dc-book-lid` 和登录时那一张一模一样。电脑上封面绕中缝翻到左边，左页（`data-side="left"`，连着半边封皮）同角度翻过来，两张在竖直时交接，整本书同时移到摊开的位置，书签随后依次滑出（`is-opening`）；手机上封面绕左边翻开。换栏目和栏内翻页都用上面的纸叶（760ms）；这台设备没印过的交易行加 `is-printing` 和 `--row`，从最早一笔起逐格印上；打开时 `dc-pb-seal` 和 `dc-pb-chop` 最后盖下，翻页时章已经在纸上；合上（`is-closing`）时书签收回、封面翻回，正好落在登录封面的位置。
- 存折版的纸面部件：`dc-pb-types` 是印在纸上的类型页签（全部、存款、取款、兑换、工资、利息、贷款），手机上平分一行；名次表里自己那一行 `is-me`（浅金底，姓名后印“我”）；`dc-pb-note` 是虚线框里的一句说明（再存多少超过前一名）；`dc-pb-rules` 是页底印的几条说明，标题取自它的 `aria-label`（户名页的“存折须知”，名次页的“排名说明”）；`dc-pb-hint` 是页内一句小字提示；页头右侧的 `small` 可印“续页”；`dc-pb-sub` 是页内的小标题（“本学期”）；`dc-pb-chop-box` 是“预留印鉴”栏，里面一枚红色方形姓名章 `dc-pb-chop`，字从右往左一列一列读，名字里的“·”不印：两个字加“之印”（王五之印），三个字加“印”（张小明印），四个字只印名字，都是两列两行；五个字加“印”、六个字只印名字，加 `is-six` 排成三列两行；七个字加“之印”、八个字加“印”，加 `is-nine` 排成三列三行，九格正好排满；九个字以上印前九个字，不加“印”。`dc-pb-actions` 把设置项（普通版、切换账号、在此设备保存登录、合上存折）放在纸面上。

- 其余部件：`dc-pb-clamp` 摘要最多两行、`dc-pb-empty` 没有记录时的一句、`dc-pb-foil` 封面烫金字；`dc-book-desk` 存折下的桌面、`dc-book-help` 封面下的说明、`dc-book-alt` 封面下的备选入口、`dc-book-pages` 翻页容器、`dc-book-marks` 书签组、`dc-book-html` 整页不滚动的根元素。
- 例外：存折模仿实物，表格和小字用 11～13px 的印刷字号，金色的“打开存折”也只在这里出现。主规范里的字号和按钮颜色规则不约束纸面。

使用者提供：户名、账号、班级、余额、本学期存入和支出；每笔交易的时间、摘要、余额变动和变动后的余额（`txns.balance_after`）；存折版另需排名和账户状态。

颜色：封皮 `#2152d0 → #163a9e`，纸页 `#f7faff`，打印墨色 `#1d2438`，印章红 `rgb(198 40 40)`，封面烫金和“打开存折” `#f3cf7a`；其余用 tokens。“打开存折”在账号和密码都填好前是金色描边的空心按钮，填好后变成实心金色。

红涨绿跌：账页“存入”一列的数字用 `rise`（红），“支出”一列用 `fall`（绿）；首页本学期存入、支出和理财盈亏同样。
