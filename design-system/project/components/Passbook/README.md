# Passbook

储蓄存折：学生的“存折版”（`StudentBookPage`）用它把整个账户印在一本存折里。这是系统里唯一按实物画的组件；普通版的学生页面和其他页面都保持平面的 DS 风格。

- 结构：`dc-passbook`（深蓝封皮，四周露出 6px）包着一页或两页 `dc-pb-page`。纸页是浅蓝底 `#f7faff` 加两层细密的防伪底纹，表头和栏线是蓝色印刷，记录用等宽字，像打印机打上去的。
- 摊开：加 `is-spread`，电脑宽度（`app` 容器 ≥1024px）左右两页并排，中缝有阴影和装订线；更窄时上下两页，接缝处是装订线。
- 页头 `dc-pb-head`：字距拉开的页名（“储蓄存折”“交易记录”），下面一条双线；右侧可放 `small`（学部、当前类型）或一个链接（“翻看全部”）。
- 户名页：`dc-pb-fields` 是带格线的“户名 / 账号 / 班级”；`dc-pb-balance` 写当前余额（等宽 44px），右侧压一枚红色圆章 `dc-pb-seal`（行名沿圆周排列，中间一颗星，下面写“业务专用章”，`aria-hidden`）；`dc-pb-sums` 写本学期存入（绿色）和支出。
- 交易页：`dc-pb-table` 六栏，依次为行号、日期、摘要、支取、存入、余额。日期印成“11-03”，下面一行小字写时间，往年的记录写年份；支取和存入各占一栏，不带正负号；摘要放不下时以省略号结尾，完整内容放在 `title` 里。现金业务的支取和存入两栏都空着，摘要下面小字写“现金支付，余额不变 · 3 HTB”。没印满的一页继续印带行号的空行（`aria-hidden`）。页脚 `dc-pb-foot` 写行名和页码。
- 封面 `dc-pb-cover`：合上的存折，深蓝封面上是金色的行名、标志和“储蓄存折”，下面贴一张白色标签 `dc-pb-label`。在存折版里封面就是锁（`dc-book-cover`）：标签上两行填“账号”（学号）和“密码”，下面金色的“打开存折”（`dc-book-unlock`，带锁图标）；密码不对时，标签左右轻晃，下面一张浅红纸条 `dc-book-error` 写原因。
- 打开的存折 `dc-book-open`：存折占满屏幕，右边缘伸出四枚书签 `dc-book-mark`（账户、明细、排名、我的），竖排文字，依次用海青、金、莓红、葡萄紫四种类别浅色；当前一枚 `aria-current="page"`，拉出得更长，文字下面有一道短线。书签随页面固定在右侧，手机上同样竖在存折右边。换栏目时纸页从右轻轻翻入。
- 纸的质感：电脑上摊开时，左右两页的外侧边缘叠着几层纸边，看得出整本的厚度；换栏目时右页从中缝翻过来（`dc-page-flip`，手机上纸页从右侧轻轻滑入）。摘要最多印两行，再多以省略号结尾。
- 存折版的纸面部件：`dc-pb-types` 是印在纸上的类型页签（全部、存款、取款、兑换、工资）；名次表里自己那一行 `is-me`（浅金底，姓名后印“我”）；`dc-pb-note` 是虚线框里的一句说明（再存多少超过前一名）；`dc-pb-rules` 是户名页底部印的“存折须知”；`dc-pb-sub` 是页内的小标题（“本学期”）；`dc-pb-chop-box` 是“预留印鉴”栏，里面一枚红色方形姓名章 `dc-pb-chop`（四个字分两列，从右往左读：张小明印，两个字的名字加“之印”）；`dc-pb-actions` 把设置项（普通版、切换账号、在此设备保存登录、合上存折）放在纸面上。

使用者提供：户名、账号、班级、余额、本学期存入和支出；每笔交易的时间、摘要、余额变动和变动后的余额（`txns.balance_after`）；存折版另需排名和账户状态。

颜色：封皮 `#2152d0 → #163a9e`，纸页 `#f7faff`，打印墨色 `#1d2438`，印章红 `rgb(198 40 40)`，封面烫金和“打开存折” `#f3cf7a`；其余用 tokens。
