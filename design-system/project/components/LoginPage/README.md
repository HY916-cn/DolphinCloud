# LoginPage

登录页示例：“海豚声呐”。海豚标志在一圈圈声呐波纹中轻轻漂浮，最前面一层海浪是白色的，下方的登录区就像从海面升起。手机上一屏放下，不需要滚动。

- 结构：`.dc-app` → `dc-login`：`dc-login-hero`（`dc-login-mark` 标志与三圈波纹、`<h1>海豚云</h1>`、一句说明、电脑上显示的三条要点 `dc-login-points`、`dc-waves is-drifting is-shore`）和 `<form class="dc-login-panel">`。
- 登录区：标题“欢迎登录”、身份切换（`Segmented`：学生 / 工作人员，带图标）、学号和密码输入框（`dc-login-field`，图标在框内，名称用 `dc-login-label` 留给读屏）、整行登录按钮、首次登录和忘记密码说明。
- 手机：上部标志区随屏幕高度伸缩，下部登录区固定；屏幕矮于 700px 时标志和标题自动缩小。平板：同手机，表单居中、最宽 440px。电脑：左侧标志区加三条要点，右侧 480px 登录面板。
- 动效：标志漂浮、海浪平移（开启“减少动态效果”时静止）。登录中按钮加 `is-loading` 并改为“正在登录”；账号或密码不对时在按钮上方放 `Notice`，并让密码框 `dc-nudge`。
