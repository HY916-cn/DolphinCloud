# RateBoard

利率看板（`/board`），不用登录：放在大厅或教室的大屏上，3 米外能看清本周的利率。

页面要简洁：便当盒式（Bento）拼块，五块大小不一的卡片拼满一屏，每块只放一类数字，数字是块里最大的字。规则见 PHASE-2 §16.4，取数的函数和字段以后端交接为准。

页面上不出现任何学生或工作人员的信息，也不出现锚点、系数这类计算参数（同学生页面）。

## 大屏版式

`BigClock` 也照此办理。

- **16:9 横屏**：
  - `dc-board` 占满整屏，是尺寸容器；里面一块 16:9 的舞台 `dc-board-stage`，随窗口等比缩放，四周多出的部分是 `surface` 底。
  - 字号以舞台宽度的 1% 为单位（`--u`）。舞台 1920 宽时：活期 123px，其他利率 88px，名称 46px，卡片标题 50px，页面标题 54px，小字 29px。
  - 电脑浏览器的窗口里同样等比显示。
- **竖屏或窄窗口**（宽不超过高）：
  - 拼块排成一列，顺序同下表，字号按窄屏放大，可以上下滚动。
  - 页头不放标志，标题独占一行。
- **颜色**：
  - 页面始终明亮，`surface` 底，卡片是白底加 `shadow-card`；活期一块用 `cloud-100` 底，托住全页最大的数字。
  - 不用类别色。
  - 红涨绿跌（`dc-pl is-up` / `is-down`）只用在指数和理财两块：指数涨跌和各档的收益，总带“+”“−”，0 不上色。
  - 活期、贷款、定期的利率不上色。
- **全屏**：页头右边 `dc-btn-secondary dc-btn-sm dc-fullscreen`，图标 `fullscreen`，文字“全屏”。
  - 进入全屏后按钮隐藏，用 Esc 退出。
  - 浏览器不支持全屏时不显示这个按钮。
  - 页面没有其他操作。
- **动效**：数字更新时直接换，不滚动、不闪。

## 结构

`dc-board` → `dc-board-stage` → `dc-board-body`，上面是页头，下面是拼块。

### 页头 `dc-board-head`

从左到右：

1. 海豚云标志。
2. `h1.dc-board-title`“海豚银行 · 本周利率”。
3. 状态 `span.dc-board-status`，取最后一次读取成功的时间：
   - 正常：“更新于 14:30:05”。
   - 读不到时保留上一次的数字，加 `is-danger` 和 `warning` 图标，写“暂时连不上，显示的是 14:29 的数据”。下一次读到后，恢复为“更新于 …”。
4. “全屏”按钮。

### 拼块 `dc-board-grid`

三列（宽度 5 : 3 : 4）、三行的网格，用 `grid-template-areas` 拼出五块：

```
┌──── 活期 ────┬── 定期 ──┬───── 指数 ─────┐
├──── 贷款 ────┤          ├───── 理财 ─────┤
│   （2×2）    │ （5 行） │    （3 行）     │
└──────────────┴──────────┴────────────────┘
```

每块是 `section.dc-board-panel` 加位置类。规格统一：

- 标题 `h2` 只写两个字，五块字号相同，不加小字说明。
- 下面只有数字：`p.dc-board-hero` 或 `dl.dc-board-list`（每行 `div > dt + dd`：左边名称，小一些，`ink-muted`；右边大数字）。行在块里上下均匀分布。

| 块 | 位置类 | 标题 | 内容 |
| --- | --- | --- | --- |
| 活期 | `is-current` | “活期” | `p.dc-board-hero` 一个大数字，所有学生相同 |
| 贷款 | `is-loan` | “贷款” | `dl.dc-board-list.is-grid`，2×2：600 分、750 分、900 分、1000 分，名称在上、数字在下 |
| 定期 | `is-term` | “定期” | 2 周、4 周、12 周、24 周、48 周 |
| 指数 | `is-index` | “指数” | 一行：参考指数名称和涨跌，如“沪深300 +0.42%” |
| 理财 | `is-tiers` | “理财” | `wealth_params.tiers` 的每一档，如“进取 ×4 +3.88%” |

写法：

- 利率保留 2 位小数，去掉末尾的 0：`2.1333` 写“2.13”，`4.50` 写“4.5”，`3` 写“3”。百分号放在 `small` 里，如 `2.13<small>%</small>`。
- 某个分数还不能贷款时，那一格写“—”。
- 指数和理财：
  - 涨跌和收益带符号，`dd` 加 `dc-pl`。
  - 各档名称后面是倍率，放在 `small` 里，如 `进取<small>×4</small>`。
  - 各档的数字是最新一天的收益率，按 12 周算：12 周的每日基础收益 + 倍率 × 系数 × 指数涨跌，再按这一档每天的上下限截断（同理财页，取后端算好的值）。页面上不写期限。
  - 最新一天不是今天时，指数一行的名称后面加日期：“沪深300 11月14日”。
  - 今天休市时，指数一行写“休市”，理财各档是基础收益。
  - 还没有行情时，指数一行写“—”，理财各档写“—”。

## 读取

- 每 60 秒读一次。
- 第一次读取前，五块显示 `Skeleton`。
- 第一次就读不到时：
  - 拼块的位置写 `p.dc-board-wait`“暂时连不上，正在重试”。
  - 页头的状态写“暂时连不上”。
  - 之后照常每 60 秒重试。
- 读不到的数一律写“—”，不显示 0。

## 无障碍

- 每一块有 `aria-label`，如“活期周利率”；`h1` 是页面标题。
- 页头的状态是 `role="status"`，读屏只在它变化时朗读。
- 文字对比度同全站，不小于 4.5:1。

使用者提供：
- 活期周利率（一个）；600、750、900、1000 分的贷款周利率。
- 五种定期的周利率。
- 理财：参考指数名称、最新一天的日期和涨跌、今天是否休市、各档的名称和倍率，以及 12 周时各档这一天的收益率。
- 最后一次读取成功的时间。
