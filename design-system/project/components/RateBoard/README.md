# RateBoard

利率看板（`/board`）：不用登录，放在大厅或教室的大屏上，3 米外能看清本周的利率。规则见 PHASE-2 §16.4，取数的函数和字段以后端交接为准。页面上不出现任何学生或工作人员的信息。

## 大屏版式

`BigClock` 也照此办理。

- **16:9 横屏**：
  - 页面是 `dc-board`，里面一块 16:9 的舞台 `dc-board-stage`，随窗口等比缩放，四周留出的部分是 `surface` 底。
  - `dc-board` 占满整屏，是尺寸容器。字号以舞台宽度的 1% 为单位（`--u`）。舞台 1920 宽时，主要数字 67px，标题 40～46px，小字 25px。小字在任何宽度下都不小于 14px。
  - 电脑浏览器窗口里同样等比显示。
- **竖屏或窄窗口**（宽不超过高）：排成一列，字号按窄屏放大，可以上下滚动。
- **颜色**：
  - 页面始终明亮：`surface` 底，面板是白底卡片加 `shadow-card`。本周锚点放在 `cloud-100` 的云朵块里。
  - 没有大面积色块，也不用类别色。
  - 红涨绿跌（`dc-pl is-up` / `is-down`）只用在指数涨跌上，并且总带“+”“−”。利率本身不上色。
- **全屏**：右下角 `dc-btn-secondary dc-btn-sm dc-fullscreen`，图标 `fullscreen`，文字“全屏”。
  - 进入全屏后按钮隐藏，用 Esc 退出。
  - 浏览器不支持全屏时不显示这个按钮。
  - 页面没有其他操作。
- **动效**：数字更新时直接换，不滚动、不闪。

## 结构

`dc-board` → `dc-board-stage` → `dc-board-body`，从上到下三部分。

### 页头 `dc-board-head`

- 左边是海豚云标志。
- 中间 `h1.dc-board-title`“海豚银行 · 本周利率”，下面 `small` 写“周利率 · 每分钟更新”。
- 右边 `p.dc-board-anchor`：`span`“本周锚点”、`b`“2.25%”，下一行 `small`“11月16日公布”。
  - 还没有公布过锚点时，`b` 写初始锚点，`small` 写“还没有公布，按初始锚点”。

### 三块面板 `dc-board-grid`

宽度比例 1.5 : 1 : 1。每块是 `section.dc-board-panel`，标题 `h2`。

| 面板 | 标题 | 表格 `dc-board-table` |
| --- | --- | --- |
| 按信用分 | “按信用分的周利率” | 列：信用分、活期、贷款。行：能贷款的最低分、600、750、900、1000 分，从低到高；最低分和某一行相同时只写一次 |
| 定期 | “定期周利率” | 列：期限、周利率。行：2 周、4 周、12 周、24 周、48 周 |
| 理财 | “理财基础收益” | 列：期限、每周。行同定期；下面 `p.dc-board-index` 写参考指数最近一个开盘日的涨跌 |

- 第一列写“600 分”“12 周”，用较小的字和 `ink-muted`；数字列用大字。
- 利率去掉末尾多余的 0，最多 4 位小数。百分号放在 `small` 里，如 `2.13<small>%</small>`。
- `dc-board-index`：
  - 左边 `span`“沪深300”，下一行 `small`“11月19日涨跌”。
  - 右边 `b.dc-pl.is-up`“+0.42%”或 `is-down`“−0.80%”；0 不上色。
  - 还没有行情时整行写“—”，不上色。

### 页脚 `dc-board-foot`

- 左边是状态，取最后一次读取成功的时间：
  - 正常：“更新于 14:30:05”。
  - 读不到：保留上一次的数字。`span.is-danger` 加 `warning` 图标，写“暂时连不上，显示的是 14:29 的数据”。下一次读到后，恢复为“更新于 …”。
- 右边是“全屏”按钮。

## 读取

- 每 60 秒读一次。
- 第一次读取前，三块面板和锚点显示 `Skeleton`。
- 第一次就读不到时：锚点写“—”，面板的位置写 `p.dc-board-wait`“暂时连不上，正在重试”，页脚写“暂时连不上”；之后照常每 60 秒重试。
- 读不到的数一律写“—”，不显示 0。

## 无障碍

- 每张表有 `aria-label`，如“按信用分的周利率”；`h1` 是页面标题。
- 页脚的状态是 `role="status"`，读屏只在它变化时朗读。
- 文字对比度同全站，不小于 4.5:1。

使用者提供：本周锚点及公布日期、按分数的活期和贷款利率、五种定期利率、五种期限的理财基础收益、参考指数名称和最近一个开盘日的涨跌、最后一次读取成功的时间。
