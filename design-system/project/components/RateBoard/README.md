# RateBoard

利率看板（`/board`），不用登录：放在大厅或教室的大屏上，3 米外能看清本周的利率和今天的理财收益。

页面要简洁：便当盒式（Bento）拼块，四块大小不一的卡片拼满一屏，每块只放一类数字，数字是块里最大的字。规则见 PHASE-2 §16.4，理财品种见 §10.10，取数的函数和字段以后端交接为准。

页面上不出现任何学生或工作人员的信息，也不出现锚点、系数、倍率这类计算参数（同学生页面）。

## 大屏版式

`BigClock` 也照此办理。

- **16:9 横屏**：
  - `dc-board` 占满整屏，是尺寸容器；里面一块 16:9 的舞台 `dc-board-stage`，随窗口等比缩放，四周多出的部分是 `surface` 底。
  - 字号以舞台宽度的 1% 为单位（`--u`）。舞台 1920 宽时：活期 123px，其他利率 88px，名称 46px，卡片标题 50px，页面标题 54px，小字 29px。
  - 电脑浏览器的窗口里同样等比显示。
- **竖屏或窄窗口**（宽不超过高）：
  - 拼块排成一列，顺序同下表，字号按窄屏放大，内容高于屏幕时自动滚动（见「自动滚动」）。
  - 页头不放标志，标题独占一行。
  - 理财每个品种占两行：名称（和它下面的小字）一行，数字在下一行靠右。
- **颜色**：
  - 页面始终明亮，`surface` 底，卡片是白底加 `shadow-card`；活期一块用 `cloud-100` 底，托住全页最大的数字。
  - 不用类别色。
  - 红涨绿跌（`dc-pl is-up` / `is-down`）只用在理财一块：各品种今天的收益率，总带“+”“−”，0 不上色。
  - 活期、贷款、定期的利率不上色。
- **全屏**：页头右边 `dc-btn-secondary dc-btn-sm dc-fullscreen`，图标 `fullscreen`，文字“全屏”。
  - 进入全屏后按钮隐藏，用 Esc 退出。
  - 浏览器不支持全屏时不显示这个按钮。
  - 页面没有其他操作。
- **动效**：数字更新时直接换，不滚动、不闪。

## 结构

`dc-board` → `dc-board-stage` → `dc-board-body`，上面是页头，下面是拼块。

### 页头 `dc-board-head`

从左到右：

1. 海豚云标志。
2. `h1.dc-board-title`“海豚银行 · 利率”，后面紧跟时间标签 `span.dc-board-when`“实时”（样式同各块的标签），表示页面每分钟自动更新。
3. 状态 `span.dc-board-status`，取最后一次读取成功的时间：
   - 正常：“更新于 14:30:05”。
   - 读不到时保留上一次的数字，加 `is-danger` 和 `warning` 图标，写“暂时连不上，显示的是 14:29 的数据”。下一次读到后，恢复为“更新于 …”。
4. “全屏”按钮。

### 拼块 `dc-board-grid`

三列（宽度 3.8 : 3.4 : 4.8，按网页字体实测：定期最宽的一行“24 周 3.25%”和理财最宽的一行“纳斯达克 100 +12.34%”都要放得下）、三行的网格（第一行略高，1.1 : 1 : 1），用 `grid-template-areas` 拼出四块：

```
┌─── 活期 ───┬── 定期 ──┬────── 理财 ──────┐
├─── 贷款 ───┤          │                  │
│  （2×2）   │ （5 行） │  （6 个品种）    │
└────────────┴──────────┴──────────────────┘
```

信用分暂停时，`dc-board-grid` 加 `is-flat-loan`：网格改为两行等高，左列活期、贷款各占一半，贷款块只放一个大数字。竖屏时照样排成一列。

每块是 `section.dc-board-panel` 加位置类。规格统一：

- 标题 `h2` 只写两个字，四块字号相同，不加小字说明。
- 标题后面紧跟一个时间标签 `span.dc-board-when`，写明这块数字是哪段时间的：活期、贷款、定期写“本周”；理财写“今天”（今天的收益率）。四块的标签样式相同（`cloud-100` 胶囊、`dolphin-deep` 字；活期块的底是 `cloud-100`，标签改白底）。
- 下面只有数字：`p.dc-board-hero` 或 `dl.dc-board-list`（每行 `div > dt + dd`：左边名称，小一些，`ink-muted`；右边大数字）。行在块里上下均匀分布。

| 块 | 位置类 | 标题 · 时间标签 | 内容 |
| --- | --- | --- | --- |
| 活期 | `is-current` | “活期” · 本周 | `p.dc-board-hero` 一个大数字，所有学生相同。活期暂停计息时写“暂停计息” |
| 贷款 | `is-loan` | “贷款” · 本周 | `dl.dc-board-list.is-grid`，2×2：600 分、750 分、900 分、1000 分，名称在上、数字在下；竖屏时改为一行一项。信用分暂停时见下文 |
| 定期 | `is-term` | “定期” · 本周 | 2 周、4 周、12 周、24 周、48 周 |
| 理财 | `is-wealth` | “理财” · 今天 | 六个品种，顺序固定：国债、黄金、沪深 300、创业板指、恒生指数、纳斯达克 100。每行名称和今天的收益率 |

写法：

- 利率保留 2 位小数，去掉末尾的 0：`2.1333` 写“2.13”，`4.50` 写“4.5”，`3` 写“3”。百分号放在 `small` 里，如 `2.13<small>%</small>`。
- 某个分数还不能贷款时，那一格写“—”。
- **活期暂停计息**（`public_rates().savings_enabled` 为 false，这时 `current` 为 0）：`p.dc-board-hero.is-paused`，写“暂停计息”，字号同列表数字（舞台 1920 宽时 88px），`ink-muted` 色；按 `savings_enabled` 判断，不写 0%。
- **信用分暂停**：网格加 `is-flat-loan`，贷款块的内容换成 `p.dc-board-hero`（600 分的利率，大小同活期）和它下面的 `p.dc-board-note`“信用分暂停，均按 600 分计”。
- **理财**：
  - 每个品种的数字是它最近计入的一天的收益率（净值的涨跌，含基准收益），`dd` 加 `dc-pl`，带符号；四舍五入后为 0 时写“0”，不上色。
  - 名称下面可以有一行小字 `dt > small.dc-board-day`（`ink-muted`，舞台 1920 宽时 29px）：
    - 这一天不是今天时，写日期“11月24日”。例如纳斯达克 100 次日早上才有，A 股品种 15:30 之前显示上一个计入的日子。
    - 这一天这个品种休市时，写“休市”，数字照常是后端给的（休市只计基准收益）。
    - 两样都有时写“11月24日 · 休市”。
  - 有没有小字，每行一样高：名称和数字上下居中。
  - 页面上不写倍率、基准加成和净值。
  - 这个品种还没有净值时，数字写“—”。

## 自动滚动

大屏前没有人去滚动页面。内容高于屏幕时（竖屏单列，或窗口太矮），由客户端脚本让 `dc-board`（滚动容器）自动上下滚动：

1. 读到数据、页面停在顶部 5 秒。
2. 以每秒 6 × `--u` 的速度向下滚（竖屏时 `--u` 是窗口宽的 3%：1080 宽约 194px/秒，390 宽约 70px/秒），约每秒滚过一行数字。用 `requestAnimationFrame` 按经过的时间累加位置，取整后写入 `scrollTop`，不用 `scroll-behavior: smooth`。
3. 到底停 5 秒，平滑回到顶部（`scrollTo({ top: 0, behavior: 'smooth' })`），在顶部停 5 秒，再向下，循环。

- 内容放得下（`scrollHeight − clientHeight` 不超过 1px）时不滚动。窗口大小或内容高度变化后重新判断，滚动位置超出新的范围时从底部继续。
- 有人触摸、点按、滚轮或按键（`pointerdown`、`wheel`、`keydown`、`touchstart`）时，暂停自动滚动 30 秒，从当时的位置接着往下滚；30 秒内再有操作就重新计时。
- 开启“减少动态效果”（`prefers-reduced-motion: reduce`）时不自动滚动，页面照常可以手动滚动；设置变化时随之开关。
- 进入全屏后照常。
- 每 60 秒数字更新时不打断滚动，位置和计时都不变。
- 第一次读取前（骨架屏）和第一次就读不到时不滚动。

## 读取

- 每 60 秒读一次。
- 第一次读取前，四块显示 `Skeleton`：数字的位置各一条，列表每行名称、数字各一条，条数同真实内容（贷款按 2×2 四格，理财六行）。占位条不写行内尺寸，由 `.dc-board .dc-skeleton` 定：高 0.9em，宽 2.2em（名称 2em），比真实内容略短；块窄时跟着缩短，不超出块。活期块的底是 `cloud-100`，占位条改白色。
- 第一次就读不到时：
  - 拼块的位置写 `p.dc-board-wait`“暂时连不上，正在重试”。
  - 页头的状态写“暂时连不上”。
  - 之后照常每 60 秒重试。
- 读不到的数一律写“—”，不显示 0。

## 无障碍

- 每一块有 `aria-label`：“活期周利率”“贷款周利率”“定期周利率”“理财各品种今天的收益率”；`h1` 是页面标题。
- 页头的状态是 `role="status"`，读屏只在它变化时朗读。
- 自动滚动不移动焦点，有人操作时暂停；“减少动态效果”时不滚动。
- 文字对比度同全站，不小于 4.5:1（`cloud-100` 底上的 `ink-muted`“暂停计息”约 5.5:1）。

使用者提供：
- 活期周利率（一个），活期是否计息。
- 信用分是否开启；600、750、900、1000 分的贷款周利率（信用分暂停时只有 600 分）。
- 五种定期的周利率。
- 理财六个品种：名称、最近计入的一天的日期和收益率、这一天是否休市，以及今天的日期（上海时间）。
- 最后一次读取成功的时间。
