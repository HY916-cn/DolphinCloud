# StudentInterestPage

学生“利息”页示例（普通版）：攒着多少活期利息、什么时候存进余额，以及每一天按多少余额、多少利率计了多少利息。

- 路由 `/student/interest`。入口两处：首页信用摘要里“攒着的利息”一行（见 `StudentHomePage`），信用页“本周利率”的活期一行（见 `StudentCreditPage`）。两处都是整行链接：行加 `is-link`，行末 `next` 箭头。
- 外壳 `AppShell`，导航当前项仍是“首页”；页头 `dc-top` 左边返回按钮（`back`，`aria-label="返回"`），标题“利息”，没有副标题。
- 数据（学生只读本人的）：`interest_profile()` 的 `pending_centi`、`rates.current`、`week_start`、`savings_enabled`；表 `interest_accruals`（`day`、`balance`、`rate`、`centi`、`settled_txn`）和 `interest_adjustments`（`day`、`balance`、`centi`、`settled_txn`）。

## 结构

- `dc-split`：左栏是按周分组的计息列表；右栏 `is-sticky is-lead` 是顶部卡和“怎么计息”。手机和平板单列，`is-lead` 让右栏排在列表上面；电脑两栏 7 : 5，右栏随页面固定。
- **顶部卡** `dc-card dc-stack`：
  - `body-lg`“攒着的利息”，下面 `amount` 大字“6.80”，单位 `<small>HTB</small>`；再下面一行 `dc-caption` 写什么时候存进余额，同首页：满 1.00 HTB 时“下周一存进余额”，不满时“满 1 HTB 再存进余额”；为负时“之前的利息有更正，之后的利息先补上这部分”。
  - `dc-kv` 几行，加起来等于攒着的利息：
    - 本周活期利率“2.13%/周”（`rates.current`，写法见“数据与后台”的“利率”）。
    - 本周已计“+6.58 HTB”：本周（周一起）每天计息记录之和。
    - 利息更正“+0.12 HTB”：还没存进余额的更正之和，可为负（“−0.05 HTB”）；没有时这一行不显示。
    - 上周留下的零头“0.10 HTB”：攒着的利息减去前两行，即上次结息留下的零头加上之前不满 1 HTB 还没存进余额的利息，可为负。
- **怎么计息** `dc-card dc-stack`：`heading`“怎么计息”，两段 `dc-text`：
  - “每天结束时，按当天结束时的活期余额计息：余额 × 活期周利率 ÷ 7，精确到 0.01 HTB。”
  - “每周一把攒着的利息中满 1 HTB 的部分存进余额，记一笔‘利息’，零头留到下周。”
  - 一行 `dc-caption` 举例：“例：余额 415 HTB，周利率 2.13%，一天的利息是 1.26 HTB。”
- **计息列表**：每周一组，组标题行 `dc-list-head`（左边 `dc-list-title`，右边 `dc-caption`），下面一个 `dc-list`。
  - 组标题：本周写“本周”，之前的写“11月2日至11月8日”（周一至周日）。
  - 右边写这一周的合计和状态：“+8.85 HTB · 已存进余额 9 HTB”，金额是这周所列各行之和，“已存进余额 N HTB”是结这周利息的那笔“利息”流水的金额（含之前的零头，所以与合计可以差不到 1 HTB）；这一周的记录还没结（`settled_txn` 为空）时写“还攒着”。
  - 每天一行 `dc-list-item is-amount`：左边日期“11月13日 星期五”，`small`“余额 415 HTB · 2.13%/周”（`balance`、`rate`）；右边 `<b>`“+1.26 HTB”（`centi`），`ink` 色。余额为 0 的那天照样一行，写“+0.00 HTB”。日期从新到旧。
  - 利息更正单独一行：左边“利息更正”，`small`“11月8日的利息 · 余额改为 452 HTB”（`day`、`balance`）；右边“+0.12 HTB”或“−0.05 HTB”。还没结的更正排在“本周”一组的最后；已结的排在结它的那笔流水所在一周的最后（结息在周一，所以是那个周一的前一周）。
  - 先显示最近 4 周，下面居中 `dc-load-more` 里一个 `dc-btn dc-btn-secondary dc-btn-sm`“加载更多”，每次再读 4 周，接着往下排；读完后按钮不显示。
- 利息金额总写两位小数，正数写“+”，负数写“−”（减号），都用正文 `ink` 色，不用红绿（见“颜色”）。页面上不出现“锚点”“系数”。

## 活期暂停计息

`savings_enabled` 为 false 时：

- 顶部卡上方一条默认色的 `Notice`（`rate` 图标，`role="status"`）：标题“活期暂停计息”，说明“暂停期间每天不计利息。之前攒着的利息照常在周一存进余额。”
- 顶部卡“本周活期利率”一行的值换成 `dc-tag`“暂停计息”（这时 `rates.current` 为 0，按 `savings_enabled` 判断，不显示 0%）（与信用分暂停的“已暂停”同一种默认标签：暂停是一种状态，不是等人处理，所以不用 `dc-tag-pending`）。其余各行照常。
- 一天计不计息，看这一天上海时间 24:00 时开关的状态。暂停的日子照常每天一行，`rate` 和 `centi` 都是 0：`small` 写“余额 415 HTB · 暂停计息”，右边“+0.00 HTB”。
- 首页“攒着的利息”和存折版第 3 页的小字前面加“活期暂停计息 · ”；信用页活期一行写“活期暂停计息，暂停期间存在活期不计利息”。

## 数据状态

| 状态 | 写法 |
| --- | --- |
| 读取中 | 顶部卡里 `Skeleton`：一行标题、一块 40px 高的金额、三行键值；列表位置 `Skeleton` 一个组标题加 5 行。外层 `aria-busy="true"`、`aria-label="正在加载利息"`。 |
| 读取失败 | 顶部卡和列表的位置各放一条 `Notice`（`dc-notice-danger`，`warning` 图标）：“暂时无法读取利息”“暂时无法读取计息记录”，说明“请稍后重试。”，下面 `dc-btn dc-btn-secondary dc-btn-sm`“重试”（`retry` 图标）。不显示 0.00 HTB。两块互不影响。 |
| 还没有计息记录 | 列表位置一个 `EmptyState`（`dc-kind-reward`，`coin` 图标）：标题“还没有计息记录”，说明“每天结束时按活期余额计一次利息，明天就能在这里看到。”；活期暂停计息时说明换成“活期暂停计息，恢复后每天结束时计一次利息。”顶部卡照常显示。 |
| 加载更多失败 | 按钮位置换成一行 `dc-caption is-danger`“暂时无法读取更早的记录”和“重试”。 |

## 示例数据

预览里的数字自洽：每天的利息 = ⌊余额 × 周利率 ÷ 7⌋（精确到 0.01 HTB），如 415 × 2.13% ÷ 7 = 1.2627，记 1.26 HTB。10月19日至10月25日合计 7.21，存进余额 7，留下 0.21；下一周 8.04 + 0.21 = 8.25，存进 8，留下 0.25；11月2日至11月8日 8.85 + 0.25 = 9.10，存进 9，留下 0.10。11月8日补录了一笔 40 HTB 的存款，当天按 452 HTB 重算多出 0.12 HTB，记为更正。本周 11月9日至11月13日共 6.58，攒着的利息 0.10 + 6.58 + 0.12 = 6.80 HTB。暂停计息的画面从 11月11日起暂停：本周 11日至 13日各一行 +0.00 HTB，9日、10日照常，攒着的利息 0.10 + 2.80 + 0.12 = 3.02 HTB。

使用者提供：`interest_profile()` 和本人的计息记录、利息更正，以及每笔结息流水的金额。
