# Segmented

分段切换：在 2～7 个并列的视图或模式间切换，例如“本周 / 本月 / 本学期”、字号“标准 / 较大 / 特大”。

- 结构：`<fieldset class="dc-seg" aria-label="时间范围">`，每段 `<label><input type="radio" name="…"><span>本月</span></label>`。
- `cloud-100` 胶囊底，一块白色滑块停在选中段下方，文字变 `dolphin-deep`；每段等宽，最小高度 44px。
- 动效：切换时白色滑块滑到新选项（240ms，`--ease-out`）。纯 CSS 实现，根据选中项的位置计算，最多 7 段；`fieldset` 里不要放 `legend`，用 `aria-label` 命名。

- 五段以上只用于柜台的业务栏：每段左右留白收窄；手机上（`app` 容器窄于 600px）排成两行，五段、六段每行三段，七段每行四段，不再有滑块，选中的一段自己带白底和下沿阴影。

使用者提供：2～7 个选项（每个不超过 4 个字）和当前项。切换后立即更新下方内容，不需要确认按钮；分类筛选数据用 `Tabs`。
