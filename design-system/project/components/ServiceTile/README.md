# ServiceTile

业务入口宫格：一个大图标 + 两个字的名称，让还不太识字的孩子也能靠图找到业务。

- 外层 `dc-tiles`（自动换行的网格，每格最小 132px），每格 `<a class="dc-tile">`。
- 图标放在 `dc-tile-icon` 里（80px 的 `cloud-100` 圆角方块，图标 56px）。
- 名称用 `body-lg`，最多 4 个字；需要补一句时用 `<small>`（“文创好物”）。
- 业务名称和顺序与柜台 SOP 卡片一致：存款、取款、兑换、查询、理财、贷款、存折、预约。

使用者提供：链接、图标（从 Icons 组里选）、名称。不要把两个业务放进一个格子，也不要在宫格里放数字或余额。
