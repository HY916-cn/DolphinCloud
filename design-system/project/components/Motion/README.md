# Motion

动效示例：把“动效”一节规定的每种动效做成可重播的小样，供设计和开发对照。

- 内容进入、办理成功、页面前进、输入有误四项在可运行脚本的预览里点“重播”播放；按下反馈直接按按钮体验；海浪持续缓慢平移。各页面示例的预览直接显示动效结束后的状态。
- 还包括分段切换与开关（直接点即可）、标签页与底部导航的滑动、数字变化、新到账高亮、选择反馈。各组件的动效见“动效”一节的“每个组件的动效”表。
- 所有示例只使用 `bundle.css` 里的 `dc-enter`、`dc-pop`、`dc-page-forward`、`dc-nudge`、`dc-bump`、`is-new`、`is-drifting` 和动效变量。
