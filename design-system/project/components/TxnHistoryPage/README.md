# TxnHistoryPage

明细示例：学生查自己的每一笔交易。

- 外壳 `AppShell`（当前为“明细”），标题“明细”。
- 左栏：`FilterBar`（搜索交易号或商品、从 / 到日期、按时段），下面按天分组的 `TxnList`，组标题“11月3日 星期二”，行里只写时间；最后是加载更早交易时的 `Skeleton`。
- 右栏“11月收支”（`SummaryList`）：10月底余额、本月存入、本月支出、当前余额，四个数相互对得上（408 + 15 − 8 = 415）。电脑上随页面固定；手机和平板排在列表下面，列表先出现。
- 没有交易时，列表位置显示 `EmptyState`。
