# TxnHistoryPage

明细示例：学生翻看存折上的每一笔交易。

- 外壳 `AppShell`（当前为“明细”），标题“明细”，副标题“存折上的每一笔”。
- 左栏：`FilterBar`（搜索交易号或商品、从 / 到日期、按时段）和 `Tabs`（全部、存款、取款、兑换、工资），下面是单页 `Passbook`：“交易明细”，每行带日期和变动后的余额，30 笔一页，“翻到更早的一页”接着往下印。
- 右栏“11月收支”（`SummaryList`）：10月底余额、本月存入、本月支出、当前余额，四个数对得上（408 + 15 − 8 = 415）。电脑上随页面固定；手机和平板排在存折下面。
- 没有交易时，存折里写“还没有交易记录”。
