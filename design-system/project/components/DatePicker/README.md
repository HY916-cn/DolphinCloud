# DatePicker

日期选择器：点开一张月历选一天，不用系统自带的日期控件，手机、平板、电脑上长得一样。用于查询某天的交易、选办理日期等。

- 结构：`<div class="dc-field dc-date">`：`<label class="dc-field-label" for>`（图标 + 字段名）、触发按钮 `dc-date-trigger`（显示“2026年10月27日 星期二”，右侧 `calendar` 图标），以及月历弹层 `dc-cal`（`role="dialog"`，关闭时加 `hidden`）。
- 月历：`dc-cal-head`（上个月 `dc-cal-nav`、标题按钮 `dc-cal-title`“2026年10月 ⌄”、下个月）、星期行 `dc-cal-week`（一 至 日，周一开头）、日期格 `dc-cal-grid dc-cal-days`（月初前用空 `<span>` 补位，每天一个 `dc-cal-day` 按钮）、月份面板 `dc-cal-months`（12 个 `dc-cal-month`，3 列）、底部 `dc-cal-foot`（一句规则说明和“今天”按钮）。
- 跳到较远的日期：点标题进入月份面板（`dc-cal` 加 `is-months`，标题变成“2026年 ⌃”），左右按钮改为上一年、下一年，点一个月份回到这个月的日历。选去年 3 月 15 日只需四步：点标题、上一年、3月、15。
- 锁定：这一项不能再改时，触发按钮加 `disabled`，换成 `lock` 图标（`cloud-100` 底、`ink-muted` 字），字段提示 `dc-field-hint` 写原因，例如“学期已开始，开始日不能再改”。锁定的字段仍显示当前日期，不打开月历。
- 日期和月份状态相同：今天或本月 `is-today`（海豚蓝细框）；选中 `aria-pressed="true"`（海豚蓝实底、白字）；不可选 `disabled`（`cloud-300` 浅字），例如今天之后的日期和月份。往后全都不可选时，下一个月或下一年按钮也禁用。
- 尺寸：触发按钮 56px 高、`line-strong` 描边，与 `Select` 一致；月历最宽 380px，在手机上与输入框同宽，日期格是方形（约 46px），月份按钮 56px 高，翻页按钮和标题按钮 44px 高。
- 键盘：打开后焦点落在选中日期上；方向键左右移一天、上下移一周，跨月自动翻页；在月份面板里左右移一个月、上下移一季度，跨年自动翻页。Enter 或空格选中；Esc 在月份面板里回到原来的日历，在日历里关闭并把焦点还给触发按钮。点月历外面也会关闭。

- 日期格的容器在 `dc-cal-grid` 上另加 `dc-cal-days`，只供脚本定位，没有样式。

使用者提供：字段名、当前日期、今天、可选范围（以及不可选的原因，写在 `dc-cal-foot`）。每个日期按钮的 `aria-label` 写完整日期（“10月27日 星期二”）。

动效：月历打开时上移淡入（`dc-rise`，160ms）；触发按钮展开时描边变 `dolphin-deep`；进入月份面板时标题箭头翻转（160ms）。
