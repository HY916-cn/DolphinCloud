# CounterServicePage

柜台办理示例：柜员找到并确认一位学生后，在同一页连续办理存款、取款、兑换，右侧「办理单」记下这次办理的每一笔，最后一次结束。

- 外壳 `AppShell`，柜台导航：办理、今日业务、考勤、我的。标题行：返回按钮（结束办理）、标题「办理」、副标题经办柜员，右侧切换账号。
- 内容从上到下：
  - `PersonCard`：姓名、班级与学号、今日还可取金额、当前余额，右侧「换一位」。办完一笔后余额随即更新。
  - `Segmented`：存款 / 取款 / 兑换 / 贷款 / 定期 / 理财 / 查询。切换只换下方录入区，学生不变；离线时只有存款可选。五项、六项时手机上排成两行，每行三项；七项时每行四项。“贷款”见 `Loan`，“定期”见 `TermDeposit`，“理财”见 `Invest`；“查询”的账户累计里加“定期合计”（`lookup_student` 的 `term_total`）和“贷款剩余”（`loan_remaining`）；`loan_overdue` 时 `PersonCard` 姓名后加 `dc-tag-danger`“贷款逾期”。
  - `dc-split`：左栏是当前业务的录入（存款 `QtyStepper`、取款金额、兑换商品宫格与付款方式）；右栏「办理单」卡片（`SummaryList`，`is-sticky`），先列已办完的业务（名称、交易号或付款方式、金额 `+22` / `−10`），再列正在办理的这笔和办理后余额，底部「结束办理（已办 N 笔）」。
  - `ActionBar`：只有当前业务的主按钮（确认存款）和合计。
- 办完一笔：`Sheet` 确认后，这笔进入办理单（`dc-pop`），录入区清空，余额更新，不跳页。点「结束办理」回到查找学生：页面顶部 `Notice` 写「张小明：办理完成」、每笔金额和当前余额，搜索框等待下一位。
- 没有步骤条：办理是一位学生的多笔业务，不是固定顺序。
- 手机：`PersonCard` 不显示头像和「换一位」，标题行返回按钮代替；办理单在录入区下方；合计放进贴底操作栏。平板：单列，办理单在录入区下方。电脑：左录入、右办理单。
- 页面以 `dc-page-forward` 进入。

## 离线存款

断网时柜台只能登记存款，存在这台设备上，联网后上传。

- 待上传：`dc-notice-coin`，`inbox` 图标，`dc-notice-body` 里标题“有 2 笔离线存款待上传”、说明“共 45 HTB，按登记时间顺序入账。”，`dc-notice-actions` 里主按钮“上传”（上传中加 `is-loading`，写“正在上传”）。
- 上传时，连不上、超时、服务器暂时出错（5xx、没有状态码）都不算失败：这笔留在待上传里，自动再试，间隔逐次加长（约 5 秒、15 秒、1 分钟、5 分钟，之后每 5 分钟），柜员也可以随时点“上传”。只有服务器按业务规则拒绝的（如账户已冻结、超过限额）才算未能入账。
- 未能入账：`Notice`（`danger`），标题“离线存款未能入账：张小明 20 HTB”，说明写原因和凭条信息“账户已冻结。10 元 × 2，11月26日 09:05 登记，请交银行管理员核对纸质凭条。”；`dc-notice-actions` 里两个按钮：`dc-btn-secondary`“重试”（处理好原因后再传一次，比如账户已解冻）、`dc-btn-ghost`“已核对，移除”。
- “已核对，移除”打开 `ConfirmSheet`“移除这笔离线存款？”，说明“请先和银行管理员核对张小明 20 HTB 的纸质凭条。移除后这笔存款不会再上传，也不能恢复。”，主按钮“移除”。
- 别的柜员登记的：默认色 `Notice`“本机另有 1 笔离线存款”“由柜员小林登记，需要该柜员登录后上传。”
