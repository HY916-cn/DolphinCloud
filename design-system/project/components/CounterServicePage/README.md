# CounterServicePage

柜台办理示例：柜员找到并确认一位学生后，在同一页连续办理存款、取款、兑换，右侧「办理单」记下这次办理的每一笔，最后一次结束。

- 外壳 `AppShell`，柜台导航：总览、办理、冲正。标题行：返回按钮（结束办理）、标题「办理」、副标题经办柜员，右侧切换账号。
- 内容从上到下：
  - `PersonCard`：姓名、班级与学号、今日还可取金额、当前余额，右侧「换一位」。办完一笔后余额随即更新。
  - `Segmented`：存款 / 取款 / 兑换。切换只换下方录入区，学生不变；离线时只有存款可选。
  - `dc-split`：左栏是当前业务的录入（存款 `QtyStepper`、取款金额、兑换商品宫格与付款方式）；右栏「办理单」卡片（`SummaryList`，`is-sticky`），先列已办完的业务（名称、交易号或付款方式、金额 `+22` / `−10`），再列正在办理的这笔和办理后余额，底部「结束办理（已办 N 笔）」。
  - `ActionBar`：只有当前业务的主按钮（确认存款）和合计。
- 办完一笔：`Sheet` 确认后，这笔进入办理单（`dc-pop`），录入区清空，余额更新，不跳页。点「结束办理」进入 `ResultPage`：「办理完成」、为谁办理了几笔、当前余额、每笔的交易号，按钮「办理下一位」。
- 没有步骤条：办理是一位学生的多笔业务，不是固定顺序。
- 手机：`PersonCard` 不显示头像和「换一位」，标题行返回按钮代替；办理单在录入区下方；合计放进贴底操作栏。平板：单列，办理单在录入区下方。电脑：左录入、右办理单。
- 页面以 `dc-page-forward` 进入。
