# Avatar

账号头像：一眼看出这个账号是谁、是什么身份。所有登录都用它：“我的”、切换账号的本机账号、学生和工作人员列表、`PersonCard`。

- 结构：`span.dc-avatar` 里一层圆形的 `dc-avatar-face`（人像 `person`，下半身被圆裁掉，像一张头像照），右下角一枚 `dc-avatar-badge` 角标。
- 角标按身份：

| 身份 | 角标图标 | 寓意 |
| --- | --- | --- |
| 学生 | `student`（书包） | 上学的孩子 |
| 柜员 | `teller`（钞票） | 在柜台收付海豚币 |
| 财务 | `accountant`（计算器） | 对账、报表 |
| 库管 | `storekeeper`（包裹） | 文创商品出入库 |
| 行长 | `president`（银行） | 管理整个海豚银行 |
| 银行管理员 | `teacher`（学士帽） | 带领银行的老师 |
| 运维员 | `sysadmin`（扳手） | 维护系统 |
| 还没分配身份 | `help`（问号） | 等管理员分配 |

- 颜色：头像底 `cloud-100`，人像 `dolphin`；角标 `dolphin-deep` 底、`on-dolphin` 图标，外面一圈 2px 和所在底色同色的描边（`--avatar-ring`），把角标从人像上分开。所有身份同一种海豚蓝，只靠角标区分，不给身份分配类别色。
- 尺寸：列表里 44px；`PersonCard` 里 56px（`is-lg`，加 `dc-person-avatar` 后为白底，手机宽度下随卡片隐藏）。
- 身份文字总是写在头像旁边（“柜员 · 账号 wang”），头像本身 `aria-hidden`。一台设备上没读到身份的账号（例如很久以前保存的），只画人像、不加角标。

使用者提供：账号的身份（学生，或六种工作身份之一，或未分配）。

动效：无；随所在卡片或列表进入。
