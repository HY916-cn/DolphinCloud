# Avatar

账号头像：一眼看出这个账号是什么身份。所有登录都用它：“我的”、切换账号的本机账号、学生和工作人员列表、`PersonCard`。

- 结构：`span.dc-avatar`，圆底上就是身份图标本身，占头像的六成，不再画人像。
- 图标按身份：

| 身份 | 图标 | 寓意 |
| --- | --- | --- |
| 学生 | `student`（学士帽） | 上学的孩子 |
| 柜员 | `teller`（钞票） | 在柜台收付海豚币 |
| 财务 | `accountant`（计算器） | 对账、报表 |
| 库管 | `storekeeper`（包裹） | 文创商品出入库 |
| 行长 | `president`（银行） | 管理整个海豚银行 |
| 银行管理员 | `teacher`（讲台白板） | 带领银行的老师 |
| 运维员 | `sysadmin`（扳手） | 维护系统 |
| 还没分配身份 | `help`（问号） | 等管理员分配 |
| 这台设备不知道身份 | `person`（人像） | 例如很久以前保存的账号 |

- 颜色：头像底 `cloud-100`，图标 `dolphin`。所有身份同一种海豚蓝，只靠图标区分，不给身份分配类别色。
- 尺寸：列表里 44px；`PersonCard` 里 56px（`is-lg`，加 `dc-person-avatar` 后为白底，手机宽度下随卡片隐藏）。
- 身份文字总是写在头像旁边（“柜员 · 账号 wang”），头像本身 `aria-hidden`。

使用者提供：账号的身份（学生，或六种工作身份之一，或未分配）。

动效：无；随所在卡片或列表进入。
