# Notice

提示条：操作结果或需要孩子注意的事，一个标题 + 一句说明。

- `dc-notice-success`（`role="status"`）：办理成功，标题带感叹号（“存款成功！”），说明里写清金额去了哪里。
- `dc-notice-danger`（`role="alert"`）：没办成，标题说发生了什么（“余额不够啦”），说明给出下一步怎么做。
- `dc-notice-coin`：奖励、积分到账。
- 默认（无修饰类）：一般信息，`cloud-100` 底。
- 图标 36px 放在左侧；成功用 `success`、警示用 `warning`、奖励用 `star`。

使用者提供：类型、标题、说明。不用“错误”“失败”“异常”这类吓人的词。
