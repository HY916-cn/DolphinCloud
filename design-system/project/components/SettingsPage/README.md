# SettingsPage

“我的”页示例（普通版）：学生看自己的账户信息，选页面样式，切换或退出账号。

- 外壳 `AppShell`（当前为“我的”），标题“我的”。
- 左栏：`PersonCard`（姓名、班级、学号），下面 `ViewSwitch`（页面样式：普通版 / 存折版），再下面 `ListGroup`：切换账号、在此设备保存登录（`Switch`）、退出账号（`is-danger`）。
- 右栏“我的账户”（`SummaryList`）：当前余额（`is-total`）、学部、学届、账户状态、本学期存入和支出。
- 手机与平板单列，右栏排在下方；电脑两栏。老师和职员的“我的”页没有“页面样式”。

## 工作人员的“我的”（M18）

- 除运维员外，各身份的“我的”页都有一张“工资账户”卡片（`SummaryList`）：已绑定写“学号 20260001 · 林小雨”，下面 `small`“工资按身份和班次发到这个账户”；没绑定写“还没有绑定工资账户”，右边按钮“绑定”。
- 绑定用 `Sheet`“绑定工资账户”：学号、这位学生的密码（`PasswordField`），说明“工资会存进这个学生账户。需要账户本人的密码，确认是本人的账户。”按钮“取消”“绑定”。密码不对时弹层里 `Notice`（`danger`）写原因；成功后 `Toast`“已绑定”。
- 已绑定的可以“更换”，流程相同。运维员的“我的”页没有这张卡片。
