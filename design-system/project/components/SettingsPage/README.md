# SettingsPage

“我的”页示例（普通版）：学生看自己的账户信息，选页面样式，切换或退出账号。

- 外壳 `AppShell`（当前为“我的”），标题“我的”。
- 左栏：`PersonCard`（姓名、班级、学号），下面 `ViewSwitch`（页面样式：普通版 / 存折版），再下面 `ListGroup`：切换账号、在此设备保存登录（`Switch`）、退出账号（`is-danger`）。
- 右栏“我的账户”（`SummaryList`）：当前余额（`is-total`）、学部、学届、账户状态、本学期存入和支出。
- 手机与平板单列，右栏排在下方；电脑两栏。老师和职员的“我的”页没有“页面样式”。

## 工作人员的“我的”

- 柜员、财务、库管、行长的“我的”页有一张“工资账户”卡片（`SummaryList`）：已绑定写“学号 20260001 · 林小雨”，下面 `small`“工资按身份和班次发到这个账户”；没绑定写“还没有绑定工资账户”，右边按钮“绑定”。银行管理员和运维员不参与考勤，没有这张卡片。
- 绑定用 `Sheet`“绑定工资账户”：学号、这位学生的密码（`PasswordField`），说明“工资会存进这个学生账户。需要账户本人的密码，确认是本人的账户。”按钮“取消”“绑定”。密码不对时弹层里 `Notice`（`danger`）写原因；成功后 `Toast`“已绑定”。已绑定的可以“更换”，流程相同。
- 签到（财务、库管、行长）：“工资账户”下面一张 `dc-card dc-duty`，写现在这个班次（13:30 前中午班，之后下午班）：
  - 还没有记录：`<b>`“下午班 · 还没有签到”，`small`“签到后由银行管理员审查，通过后计入工资。”，右边主按钮“签到”（`sign_in_attendance`）。成功后 `Toast`“已签到，等银行管理员审查”。
  - 已有记录：`<b>`“下午班”，后面接班次标记和状态文字（待审 / 已确认 / 未通过 / 已作废），`small` 写签到时间“11月16日 13:42 签到”，没有按钮。
  - 没绑定工资账户：按钮禁用，`small`“先绑定工资账户，再签到。”；没参与考勤：按钮禁用，`small`“还没有参与考勤，请银行管理员开启后再签到。”
  - 服务器拒绝时 `Notice`（`danger`）写在卡片里：`ATTENDANCE_OFF`“还没有参与考勤”“请银行管理员开启参与考勤后再签到。”；`SALARY_UNBOUND`“还没有绑定工资账户”“先绑定工资账户，再签到。”；`ALREADY_EXISTS`“这个班次已经有记录。”，并重读卡片。
- 参与考勤的人，再下面是“我的班次”，与柜台“考勤”页相同：`dc-weekbar` 选周、`Stats` 两项（有效班次、工资 HTB）、一周的班次（`dc-week-cell`，标记加文字）、`dc-shift-legend` 图例，最下面一行 `caption`“工资：中午班每个 10 HTB，下午班每个 12 HTB。”（按本人现在的身份取工资标准）。没参与考勤时写“还没有参与考勤”，说明“先绑定工资账户，再请银行管理员开启。”
