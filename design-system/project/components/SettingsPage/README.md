# SettingsPage

“我的”页示例：学生看自己的存折封面和账户信息，切换或退出账号。

- 外壳 `AppShell`（当前为“我的”），标题“我的”。
- 左栏：`Passbook` 的封面 `dc-pb-cover`（金色的“海豚银行”“储蓄存折”，标签上写户名、账号、班级），下面 `ListGroup`：切换账号、在此设备保存登录（`Switch`）、退出账号（`is-danger`）。
- 右栏“我的账户”（`SummaryList`）：当前余额（`is-total`）、学部、学届、账户状态、本学期存入和支出。
- 手机与平板单列，右栏排在下方；电脑两栏。老师和职员的“我的”页用 `PersonCard`。
