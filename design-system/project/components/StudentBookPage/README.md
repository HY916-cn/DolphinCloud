# StudentBookPage

存折版示例：学生的全部信息都在一本打开的存折里，没有导航栏和底部导航，靠存折右边的书签换栏目。

- 整页是 `dc-book`，存折 `Passbook`（`is-spread`）占满宽度，右边缘伸出四枚书签：账户、明细、排名、我的（见 `Passbook`）。
- 账户：左页“储蓄存折”（户名、账号、班级、学部，盖章的当前余额，本学期存入、支出和存款排名），右页“交易记录”印最近 9 笔，页脚“第 1 页”。
- 明细：左页“交易明细”，上方印着类型页签 `dc-pb-types`，30 行一页，“翻到更早的一页”接着印；右页“11月收支”。
- 排名：左页“小学部存款榜”名次表，自己一行浅金底并印“我”；右页“我的名次”（名次、余额、超过多少位同学，再存多少超过前一名），不在榜上时下面再印自己和前后各一名。
- 我的：左页“户主信息”（户名、账号、班级、学部、学届、账户状态，当前余额和本学期收支）；右页“存折设置”：普通版、切换账号、在此设备保存登录、合上存折（退出登录，回到封面）。
- 手机：两页上下排列，书签竖在右侧并随页面固定；电脑：两页摊开，每页至少 560px 高，换栏目时存折大小不跳。
- 这台设备记住学生上次用的是哪一版：用过存折版，下次打开就是存折版，在“我的”里换回普通版为止。
