# GuideBubble

小海豚提示：用海豚头像 + 对话气泡，一步一步带学生熟悉新功能，低年级首次使用时默认开启，高年级可以跳过。

- 头像 `dc-guide-avatar` 放海豚云 logo（Logos 组的 PNG），72px 白色圆底。
- 气泡 `dc-guide-bubble`：标题固定为“小海豚提示”（`dolphin-deep`），正文一到两句，用“你”称呼学生，先说怎么做、再说结果，语气亲切但不用“哦”“啦”等语气词。
- 多步引导时在 `dc-guide-actions` 写“第 1 步，共 3 步”，右侧放 `dc-btn-primary dc-btn-sm`（“下一步” / 最后一步写“完成”）。
- 气泡左下角圆角变小，像从海豚嘴边冒出来。

使用者提供：提示文字、步数、要指向的位置（气泡出现在目标附近，不要遮住目标）。每次只出现一个气泡；学生点“完成”或“跳过”后不再重复出现。
