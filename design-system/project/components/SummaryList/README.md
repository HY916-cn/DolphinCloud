# SummaryList

核对清单：办理前核对金额、办理后展示明细，一行一项，左边名称、右边数值。

- 结构：`<dl class="dc-kv">`，每行 `<div><dt>名称</dt><dd>数值</dd></div>`，行间用 `line` 色虚线分隔。
- 名称不被挤窄：数值很长时数值折行，名称最多占一半宽度。
- 合计行加 `is-total`：数值用 32px 加粗，单位 `HTB` 跟在后面用 `ink-muted`。
- 通常放在 `dc-card` 里，标题用 `heading`（“核对金额”）。

使用者提供：名称与数值。数值右对齐、使用等宽数字；金额写千分位，日期写“10月28日 12:20”。

动效：合计数字变化时加 `dc-bump`；列表加 `dc-stagger` 时逐行进入。
