# Button

按钮是孩子“做一件事”的地方：大、圆、像能按下去的积木。

- `dc-btn dc-btn-primary`：每屏最多一个，用于这一页最重要的动作（“确认存款”）。厚底阴影 `shadow-button`，按下时下沉 3px。
- `dc-btn dc-btn-secondary`：次要动作（“查一查”“帮帮我”），白底 + `line-strong` 描边。
- `dc-btn dc-btn-ghost`：返回、取消这类轻动作。
- `dc-btn-sm`：弹层、引导气泡里的按钮，高 44px，仍是合格的触控尺寸。
- 默认高 56px，文字用 `body-lg`；图标放在文字前：`<img class="dc-icon" src="…">`，主按钮上的图标自动垫一个白色圆底。

使用者提供：按钮文字（动词开头，2～5 个字，孩子听得懂的话：“存进去”“好的”，不写“提交”“确定操作”）、可选的图标、`disabled` 状态。禁用时把原因写在按钮上（“余额不够啦”），不要只变灰。
