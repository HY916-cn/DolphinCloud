# StudentBookLogin

存折版登录示例：只给学生的登录页，页面上只有一本合着的存折。

- 整页是 `dc-book`（`surface` 底），存折封面 `dc-book-cover` 居中：金色的“海豚银行”、标志、“储蓄存折”，标签上两行“账号”（填学号）和“密码”，下面金色的“打开存折”。按钮在两项都填好前变淡。
- 只能用学号登录：工作人员的账号在这里打不开存折。账号或密码不对时，标签左右轻晃，下面浅红纸条写“账号或密码不正确”，连错 5 次写“密码错误次数过多”。
- 封面下方一个文字链接“普通版登录”，回到 `LoginPage`。
- 首次登录、初始密码要改时，打开后先进入修改密码页，改好再回到存折。
