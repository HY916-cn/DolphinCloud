# TimePicker

时间选择器：24 小时制，点开后先点“时”、再点“分”，不用系统自带的时间控件。用于预约柜台办理时间、设置班次和提醒时间等。

- 结构：`<div class="dc-field dc-time">`：`<label class="dc-field-label" for>`（图标 + 字段名）、触发按钮 `dc-date-trigger`（显示“09:30”，右侧 `clock` 图标），以及弹层 `dc-cal`（`role="dialog"`，关闭时加 `hidden`）。触发按钮和弹层与 `DatePicker` 共用样式。
- 弹层：小标题 `dc-time-label`“时”，下面是 24 个整点 `dc-time-grid`（6 列 4 行，00–05、06–11、12–17、18–23 各一行）；小标题“分”，下面是 12 个分钟档（00、05 … 55，6 列 2 行）；底部 `dc-cal-foot` 写可选范围。每格是一个 `dc-time-opt` 按钮，文字两位数补零。
- 操作：点一个整点，触发按钮立刻更新，焦点移到分钟；点一个分钟后弹层关闭。只改分钟时直接点分钟即可。
- 状态：选中 `aria-pressed="true"`（海豚蓝实底、白字）；不可选 `disabled`（`cloud-300` 浅字），例如营业时间之外的整点。
- 尺寸：触发按钮 56px 高，与 `Select`、`DatePicker` 一致；弹层最宽 380px，每格 44px 高。
- 键盘：打开后焦点落在选中的整点上；方向键左右移一格、上下移一行，Enter 或空格选中；Esc 关闭并把焦点还给触发按钮。点弹层外面也会关闭。

使用者提供：字段名、当前时间、可选范围（以及不可选的原因，写在 `dc-cal-foot`）、分钟档的间隔（默认 5 分钟，需要精确到分钟时改为 00–59）。时、分两组各加 `role="group"` 和 `aria-label`，每个按钮的 `aria-label` 写“9时”“30分”。

动效：弹层打开时上移淡入（`dc-rise`，160ms）；触发按钮展开时描边变 `dolphin-deep`。
