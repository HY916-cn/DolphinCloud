# StudentCreditPage

学生“信用”页示例（普通版）：我的海豚信用分、能借多少、本周利率，以及我的贷款、定期、理财和每一次分数变动。

- 外壳 `AppShell`，导航：首页、明细、信用、排名、我的（信用用 `gauge` 图标）；标题“信用”，副标题“海豚信用分”。
- 内容分六块，每块上方一个 `dc-list-title` 标题（同 `SettingsPage`）：
  1. **信用分**：一张 `dc-card`，里面是大号 `CreditGauge`，带贷款额度和“再涨 N 分，额度加 5 HTB”。下方一行 `caption`：“每周一更新。按时还款、每周存钱、余额保持在 100 HTB 以上都会加分。”信用分暂停时仪表盘加 `is-paused`，`caption` 换成“信用分暂停中，所有同学都按 600 分计算额度和利率。重新开启后恢复你原来的分数。”（见 `CreditGauge`）
  2. **本周利率**：一张 `dc-card`，标题写“本周利率 · 按 680 分”。低年级学生也要一眼看懂，所以每一项都拿 100 HTB 举例，说清能多得或要多付多少，周利率作小字写在下面。卡片里是 `dc-rate-list`，每行一句举例，金额加粗（`b`），下面 `small` 写周利率（“2.13%/周”，写法见“数据与后台”的“利率”）：

     | 项目 | 举例 | 金额怎么算（周利率 r，百分数） |
     | --- | --- | --- |
     | 活期 | 活期存 100 HTB，一周多得约 **2.13 HTB** | r，四舍五入到 0.01；按天计息，所以写“约” |
     | 定期 2、4、12、24、48 周 | 定期 12 周存 100 HTB，到期拿回 **142.00 HTB** | 100 + r × 周数，舍去 0.01 以下，与到期利息的算法相同（PHASE-2 §9.5）；r 是银行管理员设定的固定周利率，不随信用分变 |
     | 贷款 | 借 100 HTB，一周利息约 **5.89 HTB** | r，四舍五入到 0.01 |

     - 金额总写两位小数，与待入账利息一致。
     - 低于能贷款的最低分时，贷款一行只写“400 分以上才能贷款”，没有小字。
     - 页面上不出现“锚点”“系数”“倍数”这类词。
     - 一共七行：活期、定期五种、贷款。
     - 列表下面一行 `caption`，先写“信用分越高，活期多得，借钱少付；定期利率是固定的。”，再接这组利率从哪来，按顺序取第一条符合的：
       - 不在学期内（今天不在任何学期的起止日之间）：“放假时活期不算利息，定期照常算。”
       - 还没有公布过利率（`week_start` 为空）：“本周利率还没有公布，先按初始利率显示。每周一公布。”
       - 其他：“11月9日公布，每周一更新。”
  3. **我的贷款**：写法见 `Loan` 的“学生‘我的贷款’”：未结清的一笔是一张 `dc-card`，一句“借了 130 HTB，还剩 **98 HTB** 没还”和下次应还，下面是还款计划（每期一行，标签：已还清、已逾期、本期、待还）；结清的每笔一行 `dc-list-item`；作废的不显示。逾期时上方 `Notice`（`danger`）。
  4. **我的定期**：`dc-list` 加 `dc-list-item`，每笔一行，写法见 `TermDeposit`：第一行“定期 12 周存 100 HTB，到期拿回 **142.00 HTB**”，`small` 写“2月4日 到期 · 3.5%/周”，右边是状态标签（存期中、已到期、已提前支取）；冲正的不显示。
  5. **我的理财**：写法见 `Invest` 的“学生‘我的理财’”：上方一句说明和本周收益率，每笔一行写本金、现在值和盈亏（`dc-pl`），右边状态标签。
  6. **信用分变动**：`TxnList` 直接放在标题下面。每次变动一行：图标 `gauge`，标题写原因（“按时还清一期”“上周有存款”），下面是时间；右边“+5”或“−50”，下方写“加分”或“减分”。加分加 `is-in`（`success` 色），减分用 `ink` 色。时间后面接着写“变动后 685 分”。信用分暂停、重新开启时的那一条同样显示，标题是它的原因（“信用分暂停，按 600 分计”），图标仍是 `gauge`。先显示最近 20 条，下面“加载更多”。
- 布局：手机和平板单列，按上面的顺序；电脑用 `dc-split` 两栏，左栏信用分和本周利率，右栏我的贷款、我的定期、我的理财、信用分变动。

## 各块的数据状态

功能还没上线的块整块不显示，不放“敬请期待”之类的占位：利率 M9、定期 M10、贷款 M11、理财 M16 上线。所以 M9 时这一页是“信用分”“本周利率”和“信用分变动”三块。下表是上线以后的写法。

| 块 | 读取中 | 读取失败 | 还没有 |
| --- | --- | --- | --- |
| 信用分 | 与仪表盘等大的 `Skeleton` | `Notice`（`danger`）“暂时无法读取信用分”，加“重试”；不显示 0 分的仪表盘 | 不会出现：开户就是 600 分 |
| 本周利率 | `Skeleton` 5 行 | 同上，“暂时无法读取本周利率” | 不会出现：总按当前利率显示，来源写在列表下面的说明里 |
| 我的贷款 | `Skeleton` 2 行 | 同上，“暂时无法读取贷款” | “没有贷款。你现在最多能借 165 HTB，在柜台申请。”；400 分以下写“没有贷款。信用分 400 分以上才能申请。” |
| 我的定期 | `Skeleton` 2 行 | 同上，“暂时无法读取定期” | “没有定期。可以在柜台把活期存成定期，存期 2、4 或 8 周，利率比活期高。” |
| 我的理财 | `Skeleton` 2 行 | 同上，“暂时无法读取理财” | “没有理财。可以在柜台用活期买理财，期限 2 到 48 周，可能赚也可能亏。” |
| 信用分变动 | `Skeleton` 3 行 | 同上，“暂时无法读取变动记录” | “还没有变动。每周一会按上周的存款和余额加减分。” |

- “还没有”是标题下面一张 `dc-card` 里的一行说明（`ink-muted`），不用大号 `EmptyState`：一页里同时出现几块大空状态会喧宾夺主。
- 某一块读取失败不影响其他块。

## 存折版

存折版不单设“信用”一栏，见 `StudentBookPage`。

使用者提供：分数、额度和“再涨 N 分”（按 `credit_curve` 算好），本周利率，贷款和定期列表，以及按时间倒序的变动记录。
