# StudentCreditPage

学生“信用”页示例（普通版）：我的海豚信用分、能借多少、本周利率，以及我的贷款、定期和每一次分数变动。

- 外壳 `AppShell`，导航：首页、明细、信用、排名、我的（信用用 `gauge` 图标）；标题“信用”，副标题“海豚信用分”。
- 内容分五块，每块上方一个 `dc-list-title` 标题（同 `SettingsPage`）：
  1. **信用分**：一张 `dc-card`，里面是大号 `CreditGauge`，带贷款额度和“再涨 N 分，额度加 5 HTB”。下方一行 `caption`：“每周一更新。按时还款、每周存钱、余额保持在 100 HTB 以上都会加分。”
  2. **本周利率**：一张 `dc-card`，里面是 `SummaryList`，每行一项：活期、定期 2 周、定期 4 周、定期 8 周、贷款，都写周利率（“2.08%/周”）。标题写“本周利率 · 按 680 分”。400 分以下，贷款一行写“400 分以上才能贷款”。
  3. **我的贷款**：`ListGroup` 直接放在标题下面，每笔一行链接，第一行“贷款 130 HTB”，`small` 写“第 2/4 期 · 下次 11月17日 应还 35 HTB”，右边是状态标签：还款中（`dc-tag`）、已逾期（`dc-tag-danger`，`warning` 图标）、已结清（`dc-tag-success`）。点开是这笔贷款的还款计划和每期状态。
  4. **我的定期**：`ListGroup`，每笔一行，第一行“定期 100 HTB · 4 周”，`small` 写“12月8日 到期 · 预计利息 3 HTB”，右边标签：未到期（`dc-tag`）、已到期（`dc-tag-success`，已转回活期）。
  5. **信用分变动**：`TxnList` 直接放在标题下面。每次变动一行：图标 `gauge`，标题写原因（“按时还清一期”“上周有存款”），下面是时间；右边“+5”或“−50”，下方写“加分”或“减分”。加分加 `is-in`（`success` 色），减分用 `ink` 色。时间后面接着写“变动后 685 分”。先显示最近 20 条，下面“加载更多”。
- 布局：手机和平板单列，按上面的顺序；电脑用 `dc-split` 两栏，左栏信用分和本周利率，右栏我的贷款、我的定期、信用分变动。

## 各块的数据状态

功能还没上线的块整块不显示，不放“敬请期待”之类的占位：利率 M9、定期 M10、贷款 M11 上线。所以 M8 时这一页只有“信用分”和“信用分变动”两块。下表是上线以后的写法。

| 块 | 读取中 | 读取失败 | 还没有 |
| --- | --- | --- | --- |
| 信用分 | 与仪表盘等大的 `Skeleton` | `Notice`（`danger`）“暂时无法读取信用分”，加“重试”；不显示 0 分的仪表盘 | 不会出现：开户就是 600 分 |
| 本周利率 | `Skeleton` 5 行 | 同上，“暂时无法读取本周利率” | “本周利率还没有公布。每周一公布。”（假期里写“假期里不计息，开学后的第一个周一公布。”） |
| 我的贷款 | `Skeleton` 2 行 | 同上，“暂时无法读取贷款” | “没有贷款。你现在最多能借 165 HTB，在柜台申请。”；400 分以下写“没有贷款。信用分 400 分以上才能申请。” |
| 我的定期 | `Skeleton` 2 行 | 同上，“暂时无法读取定期” | “没有定期。可以在柜台把活期存成定期，存期 2、4 或 8 周，利率比活期高。” |
| 信用分变动 | `Skeleton` 3 行 | 同上，“暂时无法读取变动记录” | “还没有变动。每周一会按上周的存款和余额加减分。” |

- “还没有”是标题下面一张 `dc-card` 里的一行说明（`ink-muted`），不用大号 `EmptyState`：一页里同时出现几块大空状态会喧宾夺主。
- 某一块读取失败不影响其他块。

## 存折版

存折版不单设“信用”一栏，见 `StudentBookPage`。

使用者提供：分数、额度和“再涨 N 分”（按 `credit_curve` 算好），本周利率，贷款和定期列表，以及按时间倒序的变动记录。
