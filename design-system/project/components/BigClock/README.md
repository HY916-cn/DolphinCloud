# BigClock

大屏时间（`/clock`）：不用登录，大字显示上海时间，精确到秒，以服务器时间为准。授时的做法见 PHASE-2 §16.4。大屏版式（明亮底色、全屏按钮）同 `RateBoard`。

## 结构

`div.dc-clock`（整屏）→ `div.dc-clock-body`，分成上中下三行，中间是时间：

1. `p.dc-clock-date`：日期和星期，如“11月20日 星期四”。用 `ink-muted`，贴着时间的上方。
2. `p.dc-clock-time`：`HH:mm:ss`，如“14:30:05”。24 小时制，两位补零，等宽数字，宽约占屏幕的 80%。
3. `div.dc-clock-foot`，贴在屏幕底部：
   - 左边是“全屏”按钮（`dc-btn-secondary dc-btn-sm dc-fullscreen`，图标 `fullscreen`）。
   - 右边是校准状态：校准成功时什么都不写；没有校准成功时写 `warning` 图标加“未校准”。

## 时间

- 显示的时间 = 本机时钟 + 偏差，在每个整秒刷新。
- 打开时连续调用 5 次 `server_time()`，取往返最短的一次，偏差 = 服务器时间 + 往返 / 2 − 本机时间。之后每 10 分钟重新校准。
- 校准失败时沿用上一次的偏差，并写“未校准”。从没校准成功过时显示本机时间，同样写“未校准”。
- 日期和星期按上海时间计，过零点时随时间一起更新。

## 字号

- 时间：`min(20cqw, 44cqh)`，以整屏为容器。横屏时由宽度决定，约占 80%；屏幕很扁时由高度决定，三行仍放在一屏里。
- 日期：`min(4.4cqw, 8cqh)`。
- 底部小字：不小于 14px。

## 无障碍

- `p.dc-clock-time` 不设 `aria-live`，避免读屏每秒朗读。
- 页面标题写“大屏时间”。
- 减少动态效果时同样每秒更新数字，没有过渡。

使用者提供：服务器时间、校准状态。
