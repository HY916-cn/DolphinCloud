# 动效

动效用来**说明发生了什么**：按下了、页面换了、钱存进去了。它要短、轻、可预期，不能拖慢办理，也不能让孩子分心。

## 时长与缓动

变量定义在 `components/bundle.css` 顶部，所有组件只用这些值。

| 变量 | 值 | 用于 |
| --- | --- | --- |
| `--motion-press` | 100ms | 按下与松开 |
| `--motion-quick` | 160ms | 选中、切换、颜色变化 |
| `--motion-enter` | 240ms | 卡片、提示、弹层出现，输入有误的轻摆 |
| `--motion-page` | 320ms | 页面切换、办理成功的对勾 |
| `--ease-out` | cubic-bezier(.22, 1, .36, 1) | 出现、进入：快进慢停 |
| `--ease-in` | cubic-bezier(.4, 0, 1, 1) | 离开、关闭 |
| `--ease-bounce` | cubic-bezier(.34, 1.56, .64, 1) | 只用于对勾、徽章这类小元素的轻微回弹 |

- 界面动效最长 320ms；数字滚动 600ms；超过这些时长的只有登录页的海浪平移、标志漂浮、加载占位的呼吸，以及存折版里模仿实物的翻书（见下方 `Passbook` 一行）。
- 只动 `transform` 和 `opacity`，不动宽高和位置，保证在旧平板上也流畅。

## 规定的动效

| 场景 | 做法 | 类名 |
| --- | --- | --- |
| 按下 | 主按钮、宫格下沉 3～4px，厚底变薄；圆形按钮缩到 0.9 | 组件自带 |
| 页面内容进入 | 上移 12px + 淡入，按阅读顺序每块延后 40ms，最多 6 块 | `dc-enter` + `style="--i:n"` |
| 页面前进 / 返回 | 新页面内容从右侧 24px 滑入并淡入，返回时从左侧进入；导航栏保持不动。由外壳在内容区统一加，页面不各自处理：点导航和链接算前进，按返回键或返回按钮算返回。动画结束后不保留位移，内部的 `fixed` 元素不受影响 | `dc-page-forward` / `dc-page-back` |
| 弹层 | 手机从底部升起，平板和电脑从 96% 放大并淡入；背景遮罩淡入 | `Sheet` 自带 |
| 办理成功 | 对勾 0.6 → 1 轻微回弹；余额从原值滚动到新值，600ms。余额每次变化都这样滚动，首次显示不滚动 | `dc-pop`、`data-count` |
| 输入有误 | 输入框左右轻摆一次（4px），同时出现提示文字 | `dc-nudge` |
| 开关、复选、单选 | 圆钮滑动 160ms；对勾和圆点从 0 弹到 1（`--ease-bounce`） | 组件自带 |
| 标签页、分段切换、导航 | 选中的底块或指示条滑到新位置，240ms | 组件自带 |
| 进度条 | 出现时从左向右增长，320ms | 组件自带 |
| 轻提示 | 上移淡入 240ms，3 秒后淡出 | `Toast` 自带 |
| 加载占位 | 透明度 100% ↔ 45% 缓慢呼吸，1.2 秒一次 | `Skeleton` 自带 |
| 办理中 | 按钮内出现转圈，文字改为“正在登录”“正在存款”，按钮不可再点 | `dc-btn is-loading` |
| 图标切换 | 导航选中是底块滑动，展开收起是箭头旋转 180°，完成打勾是 `dc-pop`；不做路径形变 | 组件自带 |
| 海浪 | 只在登录页缓慢平移，三层速度不同，周期 9～24 秒 | `dc-waves is-drifting` |
| 登录页标志 | 在声呐波纹中上下漂浮 6px，4 秒一次 | `LoginPage` 自带 |

## 每个组件的动效

| 组件 | 动效 |
| --- | --- |
| `Button` | 按下下沉 3px、厚底变薄（100ms）；电脑悬停时主按钮变为 `dolphin-deep`，次按钮出现 `cloud-100` 底；办理中 `is-loading` 转圈。 |
| `ServiceTile` | 按下下沉 4px（100ms）；电脑悬停时上浮 2px，图标块放大到 1.06 倍（160ms）。 |
| `BalanceCard` | 随页面以 `dc-enter` 进入；余额变化时用 `data-from` / `data-count` 从旧值滚动到新值（600ms）。 |
| `TxnList` | 列表加 `dc-stagger` 时逐条上移淡入（每条延后 40ms）；新到账的一条加 `is-new`，淡蓝底色在 1.2 秒内褪去。 |
| `Field` | 聚焦时描边和焦点环过渡（160ms）；加 `is-error` 时输入框左右轻摆一次，提示文字淡入（240ms）。 |
| `Tag` | 状态变化（如“待到账”→“已到账”）时底色和文字颜色过渡（160ms）；新出现的标签可加 `dc-pop`。 |
| `Notice` | 出现时上移 12px 淡入（240ms）。 |
| `TabBar` | 选中底块在入口之间滑动（240ms，纯 CSS，2～5 个入口）；按下时图标缩小到 0.9。 |
| `WaveDivider` | 默认静止；只在登录页加 `is-drifting` 缓慢平移。 |
| `AppShell` | 侧边导航和图标导航的选中底块上下滑动（240ms，纯 CSS，各项等高）；进入新页面时内容区加 `dc-page-forward`，返回加 `dc-page-back`，导航栏不动。 |
| `ActionBar` | 跟随页面出现，不单独移动；`dc-actions-total` 里的金额变化时加 `dc-bump`。 |
| `ChoiceCard` | 选中时描边、底色过渡（160ms），图标底轻轻弹一下（320ms，`--ease-bounce`）。 |
| `QtyStepper` | 加减按钮按下变深；卡片有张数后描边变色（160ms）；小计数字变化时加 `dc-bump`。 |
| `SummaryList` | 合计数字变化时加 `dc-bump`；列表加 `dc-stagger` 时逐行进入。 |
| `PersonCard` | 识别到学生时以 `dc-enter` 进入；余额可用 `data-count` 滚动显示。 |
| `Switch` | 圆钮滑动、轨道变色（160ms）。 |
| `Checkbox` | 对勾从 0 弹到 1（160ms，`--ease-bounce`），方框底色过渡。 |
| `Radio` | 中间圆点从 0 弹到 1（160ms，`--ease-bounce`），描边变色。 |
| `Select` | 聚焦时描边和焦点环过渡（160ms）；选项列表由系统负责。 |
| `FilterChips` | 按下缩小到 0.96；选中时对勾弹出（320ms），底色和描边过渡；电脑悬停时描边变 `dolphin`。 |
| `SearchField` | 聚焦时描边和焦点环过渡（160ms）；清除按钮出现时轻轻弹出。 |
| `Toast` | 进入时上移淡入（240ms）；离开时加 `is-leaving`，下沉淡出（160ms，`--ease-in`），动画结束后移除。 |
| `EmptyState` | 图标轻轻弹出一次（320ms），整块可随页面 `dc-enter`。 |
| `ListGroup` | 链接按下或悬停时出现浅底（160ms），电脑悬停时右箭头右移 3px。 |
| `Segmented` | 白色滑块滑到新选项，240ms，纯 CSS |
| `Tabs` | 指示条滑到新标签并改变长度，240ms，需要一段测量脚本；没有脚本时从中间展开 |
| `Progress` | 出现时从左向右增长，数值变化时平滑伸缩，320ms |
| `Sheet` | 打开 240ms（手机上升、大屏放大淡入），关闭 160ms（`is-leaving`） |
| `Result` | 对勾弹出 320ms，余额滚动 600ms，明细卡片随后进入 |
| `Skeleton` | 透明度 100% ↔ 45% 呼吸，1.2 秒一次 |
| `Passbook`（存折版） | 只在学生的存折版里，按用真存折的样子做：打开时登录的那张封面绕中缝翻到左边，第一页连着封皮同角度翻过来（1.1 秒），随后书签依次滑出；点书签换栏目和栏内按“上一页”“下一页”、滑动或方向键翻页时，一张两面都印着字的纸叶翻过去（760ms）：电脑上右页落到左边或左页翻回右边，手机上这一页绕左边翻走或上一页翻回来；没印过的交易逐行、逐格印上，打印头经过处闪一下淡蓝；打开时章最后盖下（380ms），翻页不再重盖；合上时书签收回、封面翻回（1 秒）。手机上封面和纸页绕左边装订线翻开 |
| `ViewSwitch` | 选中时描边、底色过渡（160ms），按下下沉 2px；指向存折版时小图上的封面翻开一次（900ms） |

## 通用动效类

| 类名 | 用于 |
| --- | --- |
| `dc-enter` + `--i` | 页面内容按顺序上移淡入 |
| `dc-stagger` | 给列表容器，子项依次进入（最多延后 200ms） |
| `dc-page-forward` / `dc-page-back` | 页面前进、返回 |
| `dc-pop` | 对勾、徽章这类小元素轻微回弹出现 |
| `dc-bump` | 数字变化时轻轻放大一下；移除后再加上即可重播 |
| `dc-nudge` | 输入有误时轻摆一次 |
| `is-new` | 新到账交易的淡蓝高亮 |
| `is-leaving` | `Toast`、`Sheet` 的离开动画 |

## 不做的动效

- 闪烁、抖动整个页面、旋转大面积内容（存折版的翻书除外）、视差滚动。
- 金额文字的放大缩小、彩色撒花；办理成功的庆祝只由对勾和数字完成。
- 等动画结束才能点击：动画进行中，按钮和输入框都可以立即操作。

## 减少动态效果

系统开启“减少动态效果”（`prefers-reduced-motion: reduce`）时，`bundle.css` 把所有动画和过渡缩短到 1ms：内容直接出现，海浪静止，数字直接显示结果（`data-count` 的脚本同样判断这一设置），办理中的按钮只靠文字说明状态。
