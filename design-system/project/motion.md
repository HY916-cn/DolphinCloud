# 动效

动效用来**说明发生了什么**：按下了、页面换了、钱存进去了。它要短、轻、可预期，不能拖慢办理，也不能让孩子分心。

## 时长与缓动

变量定义在 `components/bundle.css` 顶部，所有组件只用这些值。

| 变量 | 值 | 用于 |
| --- | --- | --- |
| `--motion-press` | 100ms | 按下与松开 |
| `--motion-quick` | 160ms | 选中、切换、颜色变化 |
| `--motion-enter` | 240ms | 卡片、提示、弹层出现，输入有误的轻摆 |
| `--motion-page` | 320ms | 页面切换、办理成功的对勾 |
| `--ease-out` | cubic-bezier(.22, 1, .36, 1) | 出现、进入：快进慢停 |
| `--ease-in` | cubic-bezier(.4, 0, 1, 1) | 离开、关闭 |
| `--ease-bounce` | cubic-bezier(.34, 1.56, .64, 1) | 只用于对勾、徽章这类小元素的轻微回弹 |

- 界面动效最长 320ms；数字滚动 600ms；超过这些时长的只有海浪平移。
- 只动 `transform` 和 `opacity`，不动宽高和位置，保证在旧平板上也流畅。

## 规定的动效

| 场景 | 做法 | 类名 |
| --- | --- | --- |
| 按下 | 主按钮、宫格下沉 3～4px，厚底变薄；圆形按钮缩到 0.9 | 组件自带 |
| 页面内容进入 | 上移 12px + 淡入，按阅读顺序每块延后 40ms，最多 6 块 | `dc-enter` + `style="--i:n"` |
| 页面前进 / 返回 | 新页面内容从右侧 24px 滑入并淡入，返回时从左侧进入；导航栏保持不动 | `dc-page-forward` / `dc-page-back` |
| 弹层 | 手机从底部升起，平板和电脑从 96% 放大并淡入；背景遮罩淡入 | `Sheet` 自带 |
| 办理成功 | 对勾 0.6 → 1 轻微回弹；余额从原值滚动到新值，600ms | `dc-pop`、`data-count` |
| 输入有误 | 输入框左右轻摆一次（4px），同时出现提示文字 | `dc-nudge` |
| 办理中 | 按钮内出现转圈，文字改为“正在登录”“正在存款”，按钮不可再点 | `dc-btn is-loading` |
| 图标切换 | 导航选中、展开收起、完成打勾时用 morphicons 做形变 | — |
| 海浪 | 只在登录页缓慢平移，三层速度不同，周期 9～24 秒 | `dc-waves is-drifting` |

## 不做的动效

- 闪烁、抖动整个页面、旋转大面积内容、视差滚动。
- 金额文字的放大缩小、彩色撒花；办理成功的庆祝只由对勾和数字完成。
- 等动画结束才能点击：动画进行中，按钮和输入框都可以立即操作。

## 减少动态效果

系统开启“减少动态效果”（`prefers-reduced-motion: reduce`）时，`bundle.css` 把所有动画和过渡缩短到 1ms：内容直接出现，海浪静止，数字直接显示结果（`data-count` 的脚本同样判断这一设置），办理中的按钮只靠文字说明状态。
